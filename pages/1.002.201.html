Miscellaneous Fixes

修复[edit | edit 来源]

Crash Fixes, Hangs and Soft-locks:[edit | edit 来源]

  • Fixed a crash that could occur when a large number of particles were displayed
  • Fixed a rare crash when aiming scoped 武器
  • Fixed some 崩溃 when playing bot convoy missions
  • Fixed a crash that could occur when receiving Microsoft Teams messages while playing the game

武器 and 战略配备[edit | edit 来源]

  • Fixed an issue where the weapon flashlights were flickering while using ADS
  • Fixed an issue for 能量 based 武器 not charging or overheating properly
  • Fixed an issue with wrong drag setting on the GL-21 榴弹发射器 projectiles that made them lose 速率 faster than they should have
  • Fixed an issue where shrapnel from 浮出地面-hits was forced in a roughly south-west 方向. Shrapnel should now properly fly out in a 180-ish 弧度 in the 方向 of the 浮出地面 hit

LAS-58 Talon[edit | edit 来源]

  • Fixed an visual issue when reloading in ADS
  • Fixed an issue for not being able to 换弹 without overheating
  • HUD fixes to properly show 正确 弹药 state
  • Now properly resets the 温度 to 0 when reloading
  • Fixed a visual 效果 issue when holding down the 火焰 button
  • 已移除 a minor charging delay to firing projectiles

AR-23C 解放者 Concussive[edit | edit 来源]

Some unintentional changes made their way onto the 解放者 Concussive and the Breaker during the last 补丁. This is a revert of those changes.

  • Starting 弹匣 amount从2提升至4
  • Max spare amount of magazines从5提升至6
  • Ergonomic 效果 已增加 from 0 to -10

SG-225 Breaker[edit | edit 来源]

  • Starting 弹匣 amount从6降低至5
  • Max spare amount of magazines从10降低至7

Social & Multiplayer Fixes[edit | edit 来源]

  • 已解决 an issue where the 账户 ID was not 可见 in the Options tab

Miscellaneous Fixes[edit | edit 来源]

  • Fixed an issue for the 毒气 武器, throwables and 战略配备 inverting the movement input for the 绝地潜兵
  • The Jarndiver override for the hoverpacks have been turned off 有效 today. This is reserved for 基本信息 Brasch and other Super 10 Star Generals(Fixed a bug with the draw and kick emotes that allowed 玩家 to stay floating in the air)
