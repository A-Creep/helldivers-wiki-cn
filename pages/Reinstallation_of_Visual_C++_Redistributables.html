Reinstallation of Visual C++ Redistributables

This 引导 explains how to reinstall the Visual C++ Redistributable packages. This 有时 can 解决 errors which occur if these packages are missing / are corrupted.

How to reinstall[编辑 | 编辑 来源]

Attention: 修理 Installs 通常 DO NOT 修复 problems caused by the VC++ Redistributables. Uninstalling does not equal a 修理 安装.

  • Go to 控制 Panel -> Programs -> Programs and Features
  • Look for 全部 three of the following:
    • Microsoft Visual C++ 2012 Redistributable (x64)
    • Microsoft Visual C++ 2013 Redistributable (x64)
    • Microsoft Visual C++ 2015-2022 Redistributable (x64)
  • If 任何 of the three are there, 卸载 全部 of them
  • 重新开始 the 电脑 after they have been 已移除.

一次 your 电脑 has been restarted, 安装 所有 of the following:

  • Microsoft Visual C++ 2012 Redistributable (x64)
  • Microsoft Visual C++ 2013 Redistributable (x64)
  • Microsoft Visual C++ 2015-2022 Redistributable (x64)

Alternatively you can also use the Hellbomb Script:

  • 重置 / 切换 Components 菜单
  • 卸载 VC++
  • Reboot your PC.
  • 安装 VC++
