重装 Visual C++ 运行库

故障排除
重装 Visual C++ 运行库

This guide explains how to reinstall the Visual C++ Redistributable packages. This 有时 can 解决 errors which occur if these packages are missing / are corrupted.

如何重新安装

Attention: Repair Installs 通常 DO NOT 修复 problems caused by the VC++ Redistributables. Uninstalling does not equal a Repair 安装.

  • 转到控制面板 -> 程序 -> 程序和功能
  • 查找以下全部三项：
    • Microsoft Visual C++ 2012 Redistributable (x64)
    • Microsoft Visual C++ 2013 Redistributable (x64)
    • Microsoft Visual C++ 2015-2022 Redistributable (x64)
  • 如果三个中的任何一个存在，全部卸载
  • 移除后重新启动计算机。

Once your 电脑 has been restarted, 安装 all of the following:

  • Microsoft Visual C++ 2012 Redistributable (x64)
  • Microsoft Visual C++ 2013 Redistributable (x64)
  • Microsoft Visual C++ 2015-2022 Redistributable (x64)

Alternatively you can also use the Hellbomb Script:

  • 重置/切换组件菜单
  • 卸载VC++
  • 重启电脑。
  • 安装VC++
