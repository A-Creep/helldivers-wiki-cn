Syntax Error 超级货币 are a 特殊 货币 in 绝地潜兵 2 used to buy Premium 战争债券, 传奇 战争债券, and Permanent items from the 超级商店 in the 获取 Center.

获取途径[编辑 | 编辑 来源]

  • 绝地潜兵 can 购买 超级货币 through the 采购中心 for 真实 money. They can be purchased in stacks of:
    • Syntax Error 超级货币 for $1.99 (USD)
    • Syntax Error 超级货币 for $4.99
    • Syntax Error 超级货币 for $9.99
    • Syntax Error 超级货币 for $19.99
    • Syntax Error 超级货币 for $49.99
    • Syntax Error 超级货币 for $99.99 (This is enough to buy 19 Premium 战争债券 in 全射, if combined with the 超级货币 received from 绝地潜兵动员令 and 全部 other purchased 战争债券).
  • 超级货币 can also be found in various Minor Places of Interest such as Pods, 货物 Containers, and Bunkers during missions. They will 通常 be found as a stack of Syntax Error 超级货币, but will 非常 很少 appear as a stack of Syntax Error 超级货币.
  • They can be found in 两者 the 绝地潜兵 Mobilize! 战争债券 and in 全部 Premium 战争债券.
    • the 绝地潜兵 Mobilize! 战争债券 offers a stack of 任一 Syntax Error 超级货币 or Syntax Error 超级货币 on 每个 页面 for a 全射 of Syntax Error 超级货币 throughout the 战争债券. The 费用 of 每个 stack 增加 between 每个 页面 ranging from Syntax Error 奖牌 to Syntax Error 奖牌.
    • 所有 Premium 战争债券 includes a stacks of Syntax Error 超级货币 on 每个 页面 for a 全射 of Syntax Error 超级货币 一次 the 战争债券 is completed. They 费用 Syntax Error 奖牌, Syntax Error 奖牌，或 Syntax Error 奖牌 depending on the 页面.
      • 传奇 战争债券 contain 否 Syntax Error 超级货币.
    • In 全射, between the 绝地潜兵 Mobilize! 战争债券 and the Premium 战争债券, Syntax Error 超级货币 can be earned by spending Syntax Error 奖牌.

Detailed Information[编辑 | 编辑 来源]

全射 costs are updated manually and might be outdated.
  • Minor Places of Interest spawn 更多 densely on easier difficulties ( 简单 - 中型), making them a 好 place to find 超级货币. 绝地潜兵 can 农场 Syntax Error 超级货币 by quickly and efficiently moving from Places of Interests to the 下一个.
    • The exception at these difficulties are 歼灭 类型 missions, which cannot spawn Minor Places of Interest.

    • 每个 of the twenty Premium 战争债券 costs Syntax Error 超级货币, for a collective 费用 of Syntax Error 超级货币.
    • The two 传奇 战争债券 每个 costs Syntax Error 超级货币, for a 全射 费用 of Syntax Error 超级货币.
    • The 全射 费用 of 每个 物品 from the 超级商店 is Syntax Error 超级货币:
      • the 永久目录, which features 内容 已添加 alongside the 剩余 Premium 战争债券, costs Syntax Error 超级货币.
  • In terms of 真实 money, if you're willing to 购买 超级货币 to unlock everything immediately from the 开始, you'll have to 支付 至少 $320.
    • Alternatively, you could 花费 $276 on Syntax Error 超级货币 and unlock everything eventually, if you prioritize getting the Premium 战争债券 before other 内容, and gradually 花费 your 奖牌 to get 更多 超级货币.
