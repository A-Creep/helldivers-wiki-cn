Crash On Startup

This 条款 focuses on 崩溃 on starting up the game.

基础

The quickest and easiest method to 解决 issues is via the 使用 of the Hellbomb Script.

The following are different steps you can take. It is recommended to do them one by one, 含义 you try one of the steps first and then test if the crash continues. If it does, 继续 to the 下一个 step. Please note that this guide is Windows-centric, if you need help for Linux please check Linux指南.

  1. Reboot your PC.
  2. 移除 所有 mods. This is not optional.
    • If you are using the Hellbomb Script -> 清除数据选项 Menu -> Select "Quick Mod Removal".
    • Then in the same menu, select 清除设置（Appdata）
    • Go to the 重置/切换组件 Menu -> Select "Steam Reset".
    • For manual steps, follow this guide: Broken Mods.
  3. Delete the 绝地潜兵2-folder at %appdata%/arrowhead .
    • If you are using the Hellbomb script -> Select the 清除数据选项 Menu -> Select "Clear Settings (Appdata)".
  4. Reinstallation of Visual C++ Redistributables (Check 条款 for manual steps)
    1. For the Hellbomb Script: 重置/切换组件 Menu -> "卸载 VC++".
    2. Reboot your PC.
    3. Hellbomb Script: -> 重置/切换组件 Menu -> "安装 VC++".
  5. Reinstallation of GameGuard (Click for manual steps)
    1. Hellbomb Script: 重置/切换组件 Menu -> Select "GameGuard Re-安装".
  6. Ensure your Operating System is up to date.
  7. Make sure your Virtual Memory is enabled. Make sure the Pagefile is set as "System Managed" on at least one disk.
    • 注意： This is absolutely a must for 16GB or less RAM.
  8. Set the 正确 GPU in Windows.
    1. Hellbomb Script: 图形选项 Menu -> "Select 正确 GPU".
  9. Make sure you are using one of the 推荐GPU驱动程序.
    1. If you are rolling back to a 上一个 driver version, please 下载 the 显示 Driver Uninstaller and perform a clean installation.

其他原因

There's currently an issue with Dynamic 分辨率 Scaling (DRS) crashing the game on startup. If you 经验值 this, you can manually edit your settings externally. Please try and launch the game with the steam launch 指挥 --disable-drs .
