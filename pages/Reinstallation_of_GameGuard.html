Reinstallation of GameGuard

This 条款 focuses on how to reinstall GameGuard in the event that the installation has become corrupted or you encounter other issues 相关 to the Anti-Cheat 软件.

How To

If you wish to manually reinstall GameGuard:

  1. Navigate to C:\程序 Files (x86)\Steam\steamapps\common\绝地潜兵 2\bin.
  2. Delete the "GameGuard"-folder.
  3. Navigate to C:\程序 Files (x86)\Steam\steamapps\common\绝地潜兵 2\tools.
  4. Run "gguninst.exe".
  5. Run""GGSetup.exe".
  6. Try relaunching the game.

Please Note: The actions in Steps 4 and 5 may occur so quickly that it looks like nothing happened.

If you are using the Hellbomb Script:

  1. Open the Reset/Toggle Components menu.
  2. Select "GameGuard Re-安装".
