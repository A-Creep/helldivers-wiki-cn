我能退还游戏内物品吗？

It is possible to refund items you have purchased within the game if you meet certain 标准:[5]

  • 你购买的大致时间。

战争债券代币

The 战争债券 token is a form of ingame-货币 which allows 玩家 to claim any 尊享战争债券 (but not 传奇 战争债券!) without having to spend 超级货币. You can get a 战争债券 token by buying the Super 公民 Edition of the game or upgrading your regular Version with the Super 公民 升级 DLC. This has been implemented in August 26th 2025.[11]

Please not that 传奇 战争债券 are explicitly exempt from the 使用 of 战争债券 Tokens. 传奇 战争债券 are unique 战争债券 reserved for 特殊 purposes, such as collaborations with other franchises and 费用 1.500 超级货币 instead of 1.000 超级货币.[12]

目前这些战争债券无法通过战争债券代币兑换：

无法开始任务

New 玩家 in particular might find that quick play and 难度 selectors are missing and that they can't start any missions. If you find yourself in that situation that planets are locked up (even though you should be able to access them) and you can select 两者都不 quick play nor 难度, then follow these steps:

  1. Head over to Azur Secundus in the Sten 分区 in the 终结族 正面.
  2. 检查该行星是否可用。
    • If it is available, do a 任务 on the 行星. After completing the 任务 you should now be able to select other planets and have access to both quick play and 难度 selection.
    • If the 行星 is not available to you, please 联络 the Player 支援 Team at Arrowhead's Zendesk.

银河战争地图崩溃

如果游戏在尝试更换行星时崩溃，请按照以下步骤操作：

  1. 在任何难度下故意失败任务，以使行动失败。
  2. 之后在另一颗行星上执行任务。
  3. 从大厅退回自己的飞船，然后跳转到任何活跃行星。
  4. 之后关闭游戏并重新加载——你现在应该可以自由行动了。

卡在赛博斯坦

如果你被困在生化斯坦且无法在不崩溃的情况下离开，请按照以下步骤操作：

  1. 加入另一艘当前不在生化斯坦的飞船。
  2. 在任何难度下故意失败任务，以使行动失败。
  3. 之后在任何难度下完成另一项任务。
  4. 从大厅退回自己的飞船。
  5. 在当前环绕的行星上，驾驶自己的飞船再完成一次难度1的任务
  6. 之后关闭游戏并重新加载——你现在应该可以自由行动了。

控制中心出现严重伪影

If you access the 控制 Center and it shows 庞大 artefacts, please check if you have DX11 enabled (--use-d3d11). If so, please deactivate DX11 and launch the game regularly in DX 12.

控制中心崩溃

如果游戏在互动控制中心时崩溃，请检查以下内容：

  • 尝试将游戏设置为无边框窗口而不是全屏。
  • 互动前不要切换到桌面再切回游戏。
  • 禁用动态分辨率缩放（DRS）。

没有勋章奖励

如果你没有收到奖章，应考虑以下几点：

  • 如果你的库存中有上限250枚奖章，无论来源如何，你都不会再收到更多奖章。
  • 根据最近的更改，如果你在重要指令期间未登录，将不再获得重要指令的奖章。
  • If you have participated in a 重要指令 but did not 接收 your 奖章 yet, you might need to wait for a bit. The system will hand them out in waves so as to not overburden the servers. This can take some time and some 玩家 will 接收 them sooner while others have to wait a bit. This can take some time!
    • 如果你完全没有收到奖章，建议联系Arrowhead，以便支持人员检查。

所有内容以慢动作运行

This error makes the player run in slow motion while the rest of the game seemingly has normal 速度. The exact cause for this isn't known but might be 相关 to the GPU.

  1. If you run the game with the --use-d3d11 launch 指挥, please remove it.
  2. 启用垂直同步（最好使用类似技术，如G-Sync）
  3. 将显示分辨率改为动态值，并将“渲染比例”改为“超高画质”。

    战争债券 / 超级商店

    请注意，游戏的日版与世界其他地区存在一些差异；这是因为日本有关游戏内货币和超级商店的法律。

    战争债券区/超级商店中显示为黑框或白框

    这些问题的表现是超级商店物品或战争债券部分出现方框。

    1. Please ensure you have updated your game to the latest version. If your game did not 更新 properly it cannot load the new information for recently released items and is missing crucial data.
    2. Keep in mind that especially on a fresh release the servers 接收 a high load, so it might take a bit until things have loaded properly. Give it some time and try again.
    3. Ensure that all mods are 已移除 / disabled as Broken Mods can cause such issues as well.
    4. If this issue does not 解决 itself, try and clear your shadercache.

    缺失战争债券

    如果你过去购买过战争债券，但现在无法访问，请考虑以下几点。

    1. If you've refunded a 战争债券[5] then you will have 否 access to it anymore. Please note that 战争债券 can only be refunded if you have not bought any items in them.
    2. Keep in mind that Family Sharing can cause similar issues if the game copy 变更 to another person in the Steam Family that doesn't own the game. This will then lock the 战争债券. Switching back should reverse the 问题.
    3. 如果这些都不适用，你随时可以联系Arrowhead获取进一步支持。

    白色战争债券

    如果你看到战争债券全白（横幅只是一个白框）且无法互动，请尝试以下步骤：

    1. 关闭游戏。
    2. 打开Steam，进入左上角的“设置”。
    3. 点击“下载”。
    4. 点击“清除缓存”按钮清除下载缓存。
    5. 重启Steam。

    这样你应该能让Steam检查新更新并下载包含战争债券正常运行所需全部资源的文件。

    无法购买涂装

    如果你无法购买战略配备的涂装，例如外骨骼装甲涂装，请尝试以下方法：

    1. 确保你已经购买了基础战略配备。
    2. 如果错误持续存在，请重启游戏。
    3. 如果问题持续存在，请联系Arrowhead。

    武器自定义崩溃

    This crash has become rare, but it can still 偶尔 occur. When attempting to edit the Weapon 配件 the game 崩溃 every time.

    虽然没有你可以采用的确定修复方法，但有一个临时绕开问题的变通方法。

    1. 装备你想要修改的武器。
    2. 进入任何难度下的任何任务。
    3. 开一枪。
    4. 通过完成任务或放弃任务返回飞船。

    The weapon you have equipped will now be customizable. It's tedious, but you'd have to do the same step for any other weapon you wish to customize.
