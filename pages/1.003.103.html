概述

  • Battle For 超级地球 commemorative cape!
    • Please note: Capes may take 几个 hours to 完成 deployment to all 绝地潜兵.
  • 平衡 adjustments to 尖啸虫 Mega Nests and the Leviathan
  • Fixes galore! Including a fix for the crash in the weapon customisation screen

Balancing

  • 已增加 the 生命值 of Mega 尖啸虫 nests. This change was made to make the 目标 more 挑战 and provide more varied solutions to destroying them.
  • Leviathans now have a shorter sight 射程 and will mark their 目标 with 轻型 a few 秒 before they 火焰. This change gives 玩家 a fair 警告 before being fired upon.

修复

Crash Fixes, Hangs and Soft-locks

  • Fixed crash that occurred when changing between menus in weapon customisation too quickly.
  • Fixed crash that would occur for 玩家 fighting bots with a poor 连接.
  • Fixed a freeze when generating bug city missions.
  • Fixed crash that could occur when 击倒中 光能者 Overships.

武器 and 战略配备

  • Fixed 武器 with selectable 弹药 (无后坐力炮, 机炮, etc) having their icons overwritten by the Warrant’s “Guided/Unguided” Mode.
  • P-92 Warrant
    • will no longer lock some targets when in unguided mode.
    • Fixed an issue where 锁定 would be 困难 in some environments.
    • Fixed some Z-fighting with lights on the weapon.
    • Corrected animations for the pistol's sight, it should now fold away nicely when in unguided mode.
  • AX/LAS-5 “Guard Dog” Rover: will no longer return to backpack to “换弹.”
  • AR-32 Pacifier: Fixed spent casing not ejecting from the ejection port.
  • Added Videos for the K-9 Guard Dog 和 Gl-52 De-Escalator.
  • One True Flag: Fixed an issue where planting the flag would cause 目标 items to clip through the ground.

敌人

  • Fixed some issues where 敌人 could clip into certain 地形 elements.
    • Note: We aren’t done resolving all of these issues and 继续 to 调查. Please keep the reports coming!

任务

  • Fixed an issue where horde missions would spawn at Difficulties lower than 5, which would break some functionality.
  • Fixed an issue where certain bug missions would not spawn during operations.

Miscellaneous Fixes

  • 已解决 issue with 载具 skins not having a scroll bar and 已增加 total number of skins that can be displayed.
  • 所有 cities will now 显示 in the city availability UI.
  • Fixed a bug that would show 0 玩家人数 on some cities.
  • Added more logging to track desyncs and 崩溃.
  • 已修复 Borderline 正义 armours to be more 准确 to their 属性, e.g. slight 改进 to draw 速度, etc.
