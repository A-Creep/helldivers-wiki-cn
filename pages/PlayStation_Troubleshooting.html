Basic Performance & 稳定性

Updates

通常 it is recommended to keep your 控制台 and your games updated at all times.

  • PS5系统软件： Outdated firmware can cause 稳定性 problems.
    1. Go to "Settings".
    2. Go to "System".
    3. Select "System 软件".
    4. Go to "System 软件 更新 and Settings".
    5. Select "更新 System 软件".

注意：避免使用PlayStation系统测试版固件，因为这可能会给在线服务游戏带来不可预见的稳定性问题。如有可能，请同时更新您的控制器固件。

  • 游戏更新：
    1. Highlight "绝地潜兵 2" on your PS5 home screen.
    2. Now press the "Options" button on your DualSense controller.
    3. Select "检查更新".

Clear System Cache & Rebuild 数据库

Just like computers are capable of clearing their cache so can the PS5. Especially after large game patches there's always a chance that corrupt temporary data might still be present, which in turn can cause 崩溃. Clearing the Cache and rebuilding the 数据库 can help in resolving these issues.

  1. Power off completely (do not use Rest Mode).
  2. Unplug the 控制台 for 2 分钟.
  3. Plug the 控制台 back in.
  4. Start the 控制台 into Safe Mode (for steps on how to do that, check this 章节).
  5. 连接 your controller via USB cable and press the PS button.
  6. Select "Clear System 软件 Cache" and rebuild 数据库.

Safe Mode

You can engage the PS5 in a "Safe Mode", which starts the 控制台 with only the most basic functions active. It's designed to help in resolving problems by being able to rebuild the 控制台 存储 数据库, change your 分辨率 or "困难" resetting it to 工厂 settings.[1]

⚠ Some Safe Mode options will result in the loss of Data! Make sure to back up data to a USB drive or Cloud 存储 if you want to keep it! ⚠

How to engage Safe Mode:

  1. Turn off your 控制台 by holding the power button for three 秒. The power indicator blinks for a few moments before turning off.
  2. Once the 控制台 is off, press and hold the power button again.
  3. Release it after you hear the second beep — one beep sounds when you first press, and another seven 秒 later.
  4. 连接 the controller with the USB cable and press the PS button on the controller.

Clear Game Data

Clearing the Game Data can 解决 startup 崩溃 and profile sync errors.

  1. Open the Settings.
  2. Select "Saved Data and Game/App Settings".
  3. Select "绝地潜兵 2".
  4. Delete the save file.
⚠ 绝地潜兵 2 progress re-syncs from servers. However, for other games, deleting local data will cause permanent loss if it hasn't been uploaded to PS Plus Cloud 存储. ⚠

Power & Rest Mode

The PS5 does not throttle its hardware performance during active 玩法, but it is able to engage in a sleep state. This can potentially cause memory leaks.

  1. Select "Settings".
  2. Select "System".
  3. Select "Power Saving".
  4. Adjust "Features Available in Rest Mode" and ensure that background tasks are not unexpectedly interrupting the 控制台's state while the game is suspended.
  5. If problems persist, you might want to test avoiding Rest Mode entirely and perform a 完全关机 instead once you are finished playing the game.

Temperatures

If you encounter your 控制台 suddenly shutting off, then this can 表明 problems with 温度 or power supply. It's worth observing this 行为; an 增加 in 频率 can 表明 that something is faulty. Also please check if the 问题 only occurs under 重型 load or if it happens randomly as this can 表明 what's going on.

If you are still within the warranty period and 经验值 shutoffs, you can send it in to have it repaired. Outside of warranty there are shops who offer such repair services albeit there's 否 guarantee that this will 修复 the 问题.

Opening the unit can cause severe injury or death and voids your warranty. Always consult a certified 专业 for 物理 repairs. ⚠
  1. It's 重要 to place your 控制台 in a proper position so ventilation of the 控制台 can be ensured. 小型, cramped places will interfere with airflow.
  2. You might also need to clean out the fans, especially if you are in a household with pets and smokers.
  3. Please note that the PS5 can also be placed on a 冷却 stand for additional 冷却.

Video Settings

While VRR (Variable 刷新 Rate) and high 刷新 rates 通常 改进 smoothness, they can 偶尔 cause signal dropouts or 崩溃 on certain TV/监控 firmware.

  1. Go to "Settings".
  2. Select "Screen and Video".
  3. Select "Video Output".
  4. Turn "OFF" both 120 Hz输出 和 VRR
  • Test switching between "Performance" and "Quality" presets to see if altering the 分辨率 目标 stabilizes your framerate.
  • Additionally, turn off "HDMI Device Link" in your system settings to prevent accidental power-state conflicts with your TV.

Restore 默认 & Reinstallation
