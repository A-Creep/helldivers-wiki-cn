重要 note: CLASSES ARE NOT AN IN GAME VALUE! They are solely to help this wiki categorize and group 敌人!

How Do We Categorize Each Enemy

The enemy 级别 is 本质上 a group each enemy belongs to. It depends on a few factors;

  • Main Enemy 生命值
  • 敌人护甲 Values, see the 护甲 章节 on the main 伤害 page.
    • This is the biggest factor when categorizing 敌人.
  • Enemy Size (小型, 中型, Large, 庞大)
  • How much of a 威胁 the enemy is.
  • Steps to kill the enemy when only using 支援武器


使用

{{Enemy 级别|轻型}}

While there are 10 possible classes, only 8 are currently in use. Boss is not to be used until we 实际上 see the 领袖单位 of each 阵营.

Available classes:

  1. 炮灰 - For the absolute lowest 威胁 敌人, such as Scavangers and 无票者.
  2. 轻型 - For 敌人 that are lightly 有护甲.
  3. This 级别 is currently not in use
  4. 中型 - For 敌人 that have slightly thicker 护甲, like Reinforced Scout Striders and all Devestators.
  5. This 级别 is not in use
  6. 重型 - 重型单位 Such as Chargers, Hulks, and Harvesters
  7. 超重型 - For 重型单位 that have significantly more bulk than a 重型, but are not as 困难 to defeat as a 小首领.
  8. 特殊 - For 不寻常 units such as 尖啸虫, Dropships, Warp Ships
  9. 小首领 - For units such as Bile Titans and 工厂 Striders.
  10. 首领 - The absolute best of the enemy 阵营; as of INTO THE UNJUST 更新, only 霸王虫 holds this rank.
