闪退到桌面

故障排除
闪退到桌面

本文重点介绍游戏过程中发生并将玩家弹回桌面的崩溃问题。

工作流

通常 it is recommended to use the Hellbomb Script to 速度 up the 流程 and to help you gather information on your system. Please note that this guide was written with Windows in mind. If you need help with Linux, please check this Linux 条款.

It is recommended to do them one by one, 含义 you try one of the steps first and then test if the crashing continues. If it does, 继续 to the 下一个 step.

  1. Ensure your Motherboard's UEFI / BIOS is up to date. (For more information, please read up on BIOS Updates. Please read the information carefully.)
    1. 对于 Intel 第 13 代和第 14 代 CPU 来说这绝对必要，因为它们存在只能通过微码 0x12F 遏制的硬件缺陷。
  2. 确保 Windows 已完全更新。
  3. Remove any and ALL overclocking / undervolting.
    1. 禁用 Precision Boost Overdrive、Intel Boost、ASUS MCE、XMP/EXPO/DOCP、出厂 GPU 超频等。
    2. Some AMD 5000 / 6000 / 7000 GPUs may need a 负面 core offset. For more information, please check 故障排除 System Failure#AMD GPUs.
  4. Make sure your Pagefile is enabled and set as "System Managed" on at least one disk.
    1. 对于 16GB 或更少的内存来说，这是绝对必须的。
  5. 移除所有模组——这不是可选项。
    1. If you are using the Hellbomb Script -> Clear Data Options Menu -> Select "Quick Mod Removal".
    2. Then in the same menu, select Clear Settings (Appdata)
    3. Go to the Reset/Toggle Components Menu -> Select "Steam Reset".
    4. 在 Steam 中验证游戏文件。
    • For manual steps, follow this guide: Broken Mods.
  6. Clear your shader cache (Click for Manual Steps)
    • Hellbomb Script: Clear Data Options menu. -> Select "Clear Only Shader Caches"
    • 请注意，如果你使用 DX11，则需要改为清除驱动的着色器缓存。
  7. Reinstallation of Visual C++ Redistributables (Click for manual steps)
    1. Hellbomb Script: Reset/Toggle Components Menu -> Select "卸载 VC++".
    2. 重启电脑。
    3. Hellbomb Script: Reset/Toggle Components Menu -> Select "安装 VC++".
  8. 在 Windows 中选择正确的 GPU：
    • Hellbomb Script: Graphics Options Menu -> "Select 正确 GPU".
  9. 禁用“硬件加速图形计划”（HAGS）
    1. 前往“Windows 设置”。
    2. 选择“系统”。
    3. 选择“显示”。
    4. 前往“图形设置链接”。
    5. 选择“关闭 HAGS”。
    6. 重启你的电脑。
