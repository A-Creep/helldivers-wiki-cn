验证Steam文件

⚠ Please only verify the files of ONE game at a time. Running 多个 verifications simultaneously can overload your 存储 drive and cause errors. ⚠

Many common launch 崩溃, infinite loading screens, and missing textures can be 已解决 by validating your installed game files. During this 流程, Steam scans the digital 签名 of every file in your 目录 against its 官员 servers. If it detects any files that are missing, corrupted, or altered, Steam will automatically redownload and replace only the affected data, ensuring a clean installation without touching your save files. For deeper 技术信息 insights, you can read the 官员 Steam 支援 条款 on file verification.

  1. Right-click on 绝地潜兵 2 in your Steam 图书馆.
  2. Select Properties... from the 掉落-down menu.
  3. Navigate to the Installed Files tab on the left.
  4. Click on Verify 正直 of game files.
  5. 等待验证条达到 100%，然后再启动游戏。

兼容性工具配置失败

If you are playing on Linux, you might encounter the error message "An error occurred while updating 'GAMENAME' (compatibility tool configuration failed)". This error can occur for a variety of reasons, which is why you should check different things:

  • 确保你的 Steam Runtime 4.0 已安装。
  • 验证所有已安装的 Steam Runtime（1.0 - 4.0）。
  • Make sure Proton version you want to use是实际上 installed. (This can happen if you manage Proton via 软件 such as Proton Plus and then forget to change the Proton version for 绝地潜兵 2.)
  • 验证你想使用的 Proton 版本。
  • 请确保驱动器上有足够的空间来安装 Proton 和 Steam Runtime 的关键更新。
  • 重新安装 Steam Runtime 4.0。

If the issues persist despite verifying all Runtimes and Proton Versions, please check your /.steam/steam/logs/compat_log.txt file. If you see something along the lines of Failed to load manifest for tool 4183110! then this indicates that Steam has problems with Steam Runtime 4.0 (which has the ID of 4183110).

运行时损坏

如果出于某种原因你的 Steam Runtime 已损坏（你可以通过检查 Steam 日志并查找 Runtime ID 来发现，如上所示），你会发现无法简单地卸载 Runtime，因为 Steam 不提供该选项。

You can follow one of these guides below. Manual reinstall should work just fine in most cases.

手动重新安装正在创建运行时副本

  1. 完全退出 Steam 客户端（没有托盘图标）。
  2. 找到并删除以下文件夹和文件：
    • The SteamLinuxRuntime_4 folder in ~/.local/share/Steam/steamapps/common/
    • The SteamLinuxRuntime_4-arm64 folder in ~/.local/share/Steam/steamapps/common/ (if it exists).
    • The appmanifest_4183110.acf file in ~/.local/share/Steam/steamapps/.
    • The appmanifest_4185400.acf file in ~/.local/share/Steam/steamapps/ (if it exists).
  3. 运行/打开 Steam 客户端并在库中搜索“Runtime”。
  4. 选择“Steam Linux Runtime 4”并点击“安装”。

Please Note: If you have 多个 Steam 图书馆 folders, the runtime might have been installed in one of the other libraries. Follow the same steps above for each 图书馆.

With this approach you are not removing the installed Runtime but create a healthy duplicate in the place of the corrupted one and follows a workaround as found in Valve's Github.

  1. 打开 Steam 控制台。
    • You can do this either by launching Steam with steam -控制台 or open your 终端 and 类型 in steam steam://open/控制台 while Steam is already open.
    • 这将在客户端中打开一个名为“控制台”的新标签页，允许你直接在客户端中输入命令。
  2. In the 控制台, 类型 in 下载_depot 4183110 4183111 .
    • This 指挥 tells steam to 下载 the Steam Runtime 4.0 depot again into a folder called depot_4183111 .
  3. 等待下载完成。
    • It will return something along the lines of Depot 下载 完成 : "/path/to/Steam/ubuntu12_32/steamapps/内容/app_4183110/depot_4183111" .
  4. Create a new folder: ~/.local/share/Steam/steamapps/common/Steam Linux Runtime 4.0 .
  5. Open ~/.local/share/Steam/ubuntu12_32/steamapps/内容/app_4183110/ and move the 目录 of depot_4183111 to the newly created folder.
    • 现在我们已经创建了一个带有完整 Steam Runtime 4.0 的新 Runtime 文件夹。
  6. Finally we create the appmanifest so Steam can find the new Runtime. Create a new file in ~/.local/share/Steam/steamapps/ called appmanifest_4183110.acf
  7. 将下面的代码添加到 appmanifest 中。
"AppState"
{
"appid"		"4183110"
"宇宙"		"1"
"name"		"Steam Linux Runtime 4.0"
"StateFlags"		"4"
"installdir"		"Steam Linux Runtime 4.0"
"SizeOnDisk"		"748703422"
"buildid"		"22818298"
"LastUpdated"		"1779282445"
"UpdateResult"		"0"
"BytesToDownload"		"0"
"BytesDownloaded"		"0"
}

此信息会告知Steam关于新运行时的所有必要信息，包括其位置、大小等。完成这些步骤后，请重启Steam，以便其将新运行时集成到库中。

You can check if it was successful by using your 终端 and typing in cat ~/.local/share/Steam/logs/compat_log.txt | grep "4183110" | tail -5.

  • It should show 指挥 prefix for tool 4183110 set to:.
  • If it shows unsupported version 0 this means something went wrong.

手动卸载时

Attention: Do not manually 卸载 Proton or Steam Runtime by deleting their folders in steamapps/common and their respective .vdf-files! Doing so might prevent you from reinstalling them, resulting in this error.

If you happen to remove them this way, you need to also change a third file located within userdata/USERID/config/compat.vdf, which would prevent you from reinstalling them.

  1. 完全关闭 Steam。
  2. Open the compat.vdf
  3. Find the corresponding entry associated with the tool's game ID (e.g. 1887720 for Proton 7.0).
  4. 删除该条目。
  5. Relaunch Steam. You should now be able to reinstall the Proton or Steam Runtime version.

文件验证失败

When verifying the game files for 绝地潜兵 2, Steam regularly flags a certain number of files as corrupted and then requests them again. If you then run the verification 流程 again, Steam reports the same issue with the same message. In this way, up to 16 files per verification may be flagged as corrupted.

However, this is 否 cause for concern, as it is caused by nProtect GameGuard, the game’s anti-cheat 软件. GameGuard modifies, updates and encrypts these specific files as a 安全 measure every time the game is launched. Steam’s file verification, on the other hand, compares the files on the 硬盘 with an original copy from a fresh installation stored on its servers. Consequently, all files modified by the anti-cheat system are automatically marked as "corrupt" or "无效" and replaced. This creates a constant back-and-forth between Steam and GameGuard.

This is completely normal and cannot be fixed. Furthermore, it is not an 迹象 that the installation is corrupted or that there is hardware 伤害. However, it is good practice to verify the files nonetheless:

  • Don’t ignore this 特性: Even so, it is recommended that you check the files if the game 崩溃, you encounter endless loading screens, performance drops, etc. It is a quick and 容易 first step to rule out any actual file corruption.
  • It is an indicator: You should be seriously concerned if more than 16 files cannot be verified. If this happens, it may mean that an 更新 was not carried out correctly or perhaps even that there is a 问题 with the 硬盘.

更新缓慢

In some cases, Steam may take an exceptionally long time to 更新 绝地潜兵 2. Due to the 资源-intensive nature of patching, performing a fresh uninstallation and reinstallation from scratch can ironically be the faster 解决方案.

要理解原因，看看 Steam 的 4 步更新管线会有所帮助：

  1. 下载: Steam downloads heavily compressed 更新 files.
  2. Staging: Steam creates a temporary copy of the affected multi-gigabyte game archives.
  3. Patching: Your drive unpacks the archives, injects the new data, and repacks them.
  4. Deployment: The newly updated archives replace the old files in your game 目录.

Because games like 绝地潜兵 2, "ARK", or "PayDay 2" store data in 庞大, bundled file structures, even a tiny 补丁 forces Steam to move, unpack, and rewrite tens of gigabytes. A fresh installation completely skips the staging and patching phases, writing the data sequentially instead.

补丁性能

Please be aware that there's a significant difference between downloading and updating. Before Steam can 补丁 any files, it must first 下载 the new data from the 互联网.

如果下载速度为 0 b/s，但存储驱动器活动很高，这并不意味着更新已停止——只是意味着 Steam 当前没有下载任何额外文件，而是在应用已下载到游戏的文件。

However, as shown above, the game files have to go through additional steps when patching. If the 流程 is very slow, then that's an indicator for the 存储 device to be causing a 瓶颈. Moving / copying files requires additional space on your 存储. 通常 speaking the 补丁 requires at least as much free 存储 space as the game itself takes up. If there is insufficient free 存储 space, Steam will either abort the 下载 or offload the 流程 to another, possibly slower 存储 device on which a Steam 图书馆 is located.

As it also has to unpack heavily compressed files, this 流程 takes up considerable load on your CPU for unpacking and organizing the 补丁. The unpacking is done in real-time which means any other processes that are currently running might be interfering with your performance or 经验值 stuttering for the 持续时间 of the patching 流程, depending on your hardware.

存储驱动器

It is possible to 经验值 slow patching speeds even with the 使用 of SSDs. A lot of budget solutions are particularly slow when updating the game.

如果你想检查存储设备

  1. 打开任务管理器
  2. 点击“性能”标签页。
  3. Check the active time of your disk. If it's 100%, then you have the 确认 that slow patching是实际上 cause by your 存储 device.

不过，重要的是要注意，仅打补丁过程缓慢并不意味着驱动器本身有问题；这种速度也可能由其他因素引起，例如：

  • Anti-Virus 软件 constantly scans during the patching 流程. This can be 已解决 by deactivating the Anti-Virus for the 持续时间 of the 补丁.
  • 几乎满的存储设备和需要足够空间来快速更新的修补过程。
    • While in the past this was approximated at ~110 GB, these days giving it 50+ GB is recommended. Additional space, especially on the drive that contains your Operating system is good for the pagefile (see Virtual Memory) as well as files like hiberfil.sys and obviously driver & windows updates. Extra headroom is 正面 for a system's performance.
    • Please note that having sufficient free space does not mean that the 补丁 is guaranteed to be done quickly, just that it will eventually 补丁. If your SSD is filled over 50% of its 容量, you may 经验值 slow updates due to your SSD encountering problems when being nearly full.
  • 如果你将 Steam 安装在慢速 SSD 或 HDD 上，即使将《绝地潜兵》移动到不同的快速存储，Steam 也可能很慢。

In the event of your 目标 device having insufficient space for 绝地潜兵 2, Steam will opt to utilize other drives with existing Steam Libraries instead. Especially during larger updates, Steam prefers using the largest available 存储 device with an existing Steam 图书馆 on it to ensure a successful 更新.
In practical terms this means that even if your 绝地潜兵 2 installation is located on an SSD, if that SSD has insufficient space, Steam might use a slower HDD instead to handle the operations necessary to 补丁 the game.[1] It is possible to circumvent this by removing the larger drive from your 图书馆 before patching and then adding it back in after the 补丁 is done.

If you wish to analyze whether Steam is using your SSD, open up your Task Manager and check which drive is currently in use. If you 确认 that the wrong drive is used for the patching 流程, you can follow these steps:

  1. 退出 Steam
  2. Open the folder where Steam is installed and open the /steamapps/-folder. The 默认 installation folder is C:\程序 Files (x86)\Steam\steamapps.
  3. Look for the libraryfolders.vdf-file and open it with Notepad.
  4. Then make note of the C:/.../steam number for your SSD. It is 通常 either 0 or 1 .
  5. Go back into /steamapps/ and look for the file appmanifest_553850. This is the HD2 下载 instructions file, open it with notepad.
  6. Look for the code line Stagingfolder and change the number to your SSD. Once this has been set, save the file and close it.
  7. 现在通过 Steam 左上角的按钮打开 Steam 设置。
  8. Navigate to 下载 and press Clear Caches. This will 重新开始 Steam and you will have to log in again. Note: clearing the caches WILL wipe any 下载 progress on the 补丁 so you have to 重新开始 it again.
  9. Steam 重启并重新登录后，它现在应该正在使用 SSD！

下载区域

如果存储设备没有问题，慢速可能由 Steam 的下载区域引起。

Steam distributes game files via localised “内容 运送 Networks” (CDNs). When a popular game such as 绝地潜兵 2 receives a major 更新, the 下载 servers in regions with high player counts can 有时 become heavily congested, which can bring 下载 speeds for 玩家 to a crawl. If you’re having issues with 下载 performance, it can 有时 help to change the 下载 region to access a 网络 that’s less congested – perhaps because 玩家 there are living in a different time zone and there’s less activity at that moment.

如何更改 Steam 下载区域：

  1. Click on Steam in the top-left corner of the client and select Settings.
  2. Navigate to the Downloads tab on the left 侧边栏.
  3. Locate the 下载 Region 掉落-down menu.
  4. 选择不同的区域（例如，如果你在欧洲，从德国切换到荷兰或人口较少的邻国可能会有帮助）。
  5. Steam 会提示你重启客户端以使更改生效。

Steam磁盘写入错误

It's possible to encounter the "Disk Write Error" during installing or patching 绝地潜兵 2. Because Steam doesn't specify what exactly is causing it, this error might be caused by a 许可 冲突, a blocked file or even an underlying drive instability.

快速重启：

  1. 完全关闭 Steam（通过任务管理器或任务栏图标）。
  2. 重启Steam。
  3. 如果失败，请重启电脑以释放任何被锁定的系统文件。

以管理员身份运行 Steam，以提升 Steam 的权限，绕过限制性的 Windows 文件夹保护：

  1. 完全关闭 Steam。
  2. 右键单击 Steam 桌面快捷方式，然后选择“以管理员身份运行”。

Clear the 下载 Cache. This will flush temporary installation files and force Steam to 刷新 the 下载 管道. Please be aware that this will log you out of Steam temporarily and 重新开始 the client:

  1. 导航到“Steam”（左上角）。
  2. 点击“设置”。
  3. 导航到“下载”。
  4. 点击“清除下载缓存”旁边的“清除缓存”按钮。

修复存储文件夹以修复 Steam 目录中损坏的文件夹权限：

  1. 导航到“Steam”（左上角）。
  2. 点击“设置”。
  3. 导航到“存储”。
  4. 点击驱动器细分栏旁边的三个点“...”。
  5. 从下拉菜单中选择“修复文件夹”。

你可以尝试的其他步骤：

  • Configure your Antivirus Exceptions. In case you have an 激进 third-party antivirus 软件 or Windows 捍卫者 falsely flags 绝地潜兵 2 or its anti-cheat files, locking the drive. Add your installation folder or the "绝地潜兵2.exe" to your antivirus exclusion list.
  • Free Up 存储 Space. Ensure your drive has ample free space, which is especially 重要 for patches that 要求 庞大 temporary overhead.

检查驱动器错误（Windows chkdsk）：如果错误持续存在，Windows 可能在与损坏的文件系统扇区作斗争。

  1. 打开 Windows 搜索栏，输入 `cmd`，右键单击“命令提示符”，然后选择“以管理员身份运行”。
  2. 类型 chkdsk c: /f /r (replace c: with the actual drive letter where your game is installed) and press "Enter".
  3. 按照屏幕提示扫描并修复存储设备。

10002018 Steam AppID错误

在极少数情况下，你可能会遇到编号为 10002018 的 Steam AppID 错误，可以尝试以下步骤（并非详尽无遗）：

  • 完全重新安装游戏。
  • 更新 all apps as 标注为 installed in the Microsoft Store. This also goes for 软件 such as "myHP".

第三方密钥

请注意，在 Steam 之外购买游戏密钥（除 Humble Bundle 等来源外）总是有风险的，因为犯罪分子倾向于使用密钥市场进行活动。

If a key was originally purchased using a stolen credit card or fraudulent 付款 method, the publisher will eventually trigger a chargeback. The criminals will 接收 real money for selling those keys; eventually the keys are flagged and revoked, which in turn leads to the game disappearing from your Steam 图书馆 and you will lose the 能力 to 更新 or re-下载 the game.

Please note that any transactions on gray-market platforms are done entirely at your own risk. It's strongly recommended to use developer-approved storefronts (such as Humble Bundle) instead, to avoid purchasing keys that come from a potentially 罪犯 activity. If your key has been revoked you will not 接收 any reimbursement or compensation from Valve or any other party and you cannot claim a refund through Steam 支援. Any dispute or refund requests must be handled entirely through the storefront where you bought the key, which often 提供 little to 否 buyer 保护.
