验证Steam文件

⚠ Please only verify the files of ONE game at a time. Running 多个 verifications simultaneously can overload your 存储 drive and cause errors. ⚠

Many common launch 崩溃, infinite loading screens, and missing textures can be 已解决 by validating your installed game files. During this 流程, Steam scans the digital 签名 of every file in your 目录 against its 官员 servers. If it detects any files that are missing, corrupted, or altered, Steam will automatically redownload and replace only the affected data, ensuring a clean installation without touching your save files. For deeper 技术信息 insights, you can read the Steam官方支持文章：文件验证.

  1. Right-click on 绝地潜兵2 in your Steam 图书馆.
  2. 选择 属性... from the 掉落-down menu.
  3. Navigate to the 已安装的文件 tab on the left.
  4. 点击 验证游戏文件完整性.
  5. Wait for the validation bar to reach 100% before launching the game.

兼容性工具配置失败

If you are playing on Linux, you might encounter the error message "An error occurred while updating 'GAMENAME' (compatibility tool configuration failed)". This error can occur for a variety of reasons, which is why you should check different things:

  • Make sure that your Steam Runtime 4.0 is installed.
  • Verify all installed Steam Runtimes (1.0 - 4.0).
  • Make sure Proton version you want to use是实际上 installed. (This can happen if you manage Proton via 软件 such as Proton Plus and then forget to change the Proton version for 绝地潜兵 2.)
  • Verify the Proton version you want to use.
  • Please ensure you have sufficient space on your drives to 安装 crucial updates for Proton and Steam Runtime.
  • Reinstall the Steam Runtime 4.0.

If the issues persist despite verifying all Runtimes and Proton Versions, please check your /.steam/steam/logs/compat_log.txt file. If you see something along the lines of 无法加载工具4183110的清单文件！ then this indicates that Steam has problems with Steam Runtime 4.0 (which has the ID of 4183110).

运行时损坏

If, for whatever reason, your Steam Runtime has become corrupted (which you can find out by checking Steam Logs and looking for the Runtime ID, as seen above) you'll find that simply uninstalling the Runtime isn't possible as Steam doesn't offer an option.

You can follow one of these guides below. Manual reinstall should work just fine in most cases.

手动重新安装正在创建运行时副本

  1. Exit out of the Steam client completely (否 tray icon).
  2. Find and delete the following folders and files:

采用此方法时，您不会移除已安装的运行时，而是在损坏的运行时所在位置创建一个健康的副本，并遵循Valve的变通方案 Github.

    • You can do this either by launching Steam with steam -控制台 或打开您的终端并输入 steam steam://open/控制台 当Steam已处于开启状态时。

  2. In the 控制台, 类型 in 下载_depot 4183110 4183111 .
    • This 指挥 tells steam to 下载 the Steam Runtime 4.0 depot again into a folder called depot_4183111 .
  3. Wait for the 下载 to 完成.
    • It will return something along the lines of 仓库下载完成："/path/to/Steam/ubuntu12_32/steamapps/内容/app_4183110/depot_4183111 .
  4. Create a new folder: ~/.local/share/Steam/steamapps/common/Steam Linux Runtime 4.0 .
  5. 打开 ~/.local/share/Steam/ubuntu12_32/steamapps/内容/app_4183110/ 并将以下内容移动 depot_4183111 到新创建的文件夹中。
    • Now we have created a new Runtime folder with an intact Steam Runtime 4.0.
  6. Finally we create the appmanifest so Steam can find the new Runtime. Create a new file in ~/.local/share/Steam/steamapps/ called appmanifest_4183110.acf
  7. Add the code below into the appmanifest.

此信息会告知Steam关于新运行时的所有必要信息，包括其位置、大小等。完成这些步骤后，请重启Steam，以便其将新运行时集成到库中。

您可以通过打开终端并输入以下命令来检查是否成功 cat ~/.local/share/Steam/logs/compat_log.txt | grep "4183110" | tail -5.

  • It should show 工具4183110的命令前缀设置为：.

手动卸载时

注意： Do 非手动 卸载 Proton or Steam Runtime by deleting their folders in steamapps/common and their respective .vdf-files! Doing so might prevent you from reinstalling them, resulting in this error.

If you happen to remove them this way, you need to also change a third file located within userdata/USERID/config/compat.vdf, which would prevent you from reinstalling them.

  1. Close Steam completely.
  2. 打开 compat.vdf
  3. Find the corresponding entry associated with the tool's game ID (e.g. 1887720 for Proton 7.0).
  4. Delete the entry.
  5. Relaunch Steam. You should now be able to reinstall the Proton or Steam Runtime version.

文件验证失败

When verifying the game files for 绝地潜兵 2, Steam regularly flags a certain number of files as corrupted and then requests them again. If you then run the verification 流程 again, Steam reports the same issue with the same message. In this way, up to 16 files per verification may be flagged as corrupted.

However, this is 否 cause for concern, as it is caused by nProtect GameGuard, the game’s anti-cheat 软件. GameGuard modifies, updates and encrypts these specific files as a 安全 measure every time the game is launched. Steam’s file verification, on the other hand, compares the files on the 硬盘 with an original copy from a fresh installation stored on its servers. Consequently, all files modified by the anti-cheat system are automatically marked as "corrupt" or "无效" and replaced. This creates a constant back-and-forth between Steam and GameGuard.

This is completely normal and cannot be fixed. Furthermore, it is not an 迹象 that the installation is corrupted or that there is hardware 伤害. However, it is good practice to verify the files nonetheless:

  • 请勿忽略此功能: Even so, it is recommended that you check the files if the game 崩溃, you encounter endless loading screens, performance drops, etc. It is a quick and 容易 first step to rule out any 实际 file corruption.
  • 这是一个指示器: You should be seriously concerned if more than 16 files cannot be verified. If this happens, it may mean that an 更新 was not carried out correctly or perhaps even that there is a 问题 with the 硬盘.

更新缓慢

In some cases, Steam may take an exceptionally long time to 更新 绝地潜兵 2. Due to the 资源-intensive nature of patching, performing a fresh uninstallation and reinstallation from scratch can ironically be the faster 解决方案.

To understand why, it helps to look at Steam's 4-step 更新 管道:

  1. 下载: Steam downloads heavily compressed 更新 files.
  2. 暂存: Steam creates a temporary copy of the affected multi-gigabyte game archives.
  3. 修补中: Your drive unpacks the archives, injects the new data, and repacks them.
  4. Deployment: The newly updated archives replace the old files in your game 目录.

Because games like 绝地潜兵 2, "ARK", or "PayDay 2" store data in 庞大, bundled file structures, even a tiny 补丁 forces Steam to move, unpack, and rewrite tens of gigabytes. A fresh installation completely skips the staging and patching phases, writing the data sequentially instead.

补丁性能

Please be aware that there's a significant difference between 下载中 和 更新中. Before Steam can 补丁 any files, it must first 下载 the new data from the 互联网.

If the 下载 速度 is at 0 b/s but 存储 drive activity is high, this does not mean that the 更新 has been stopped – it simply means that Steam is not currently downloading any additional files and is instead applying the files that have been downloaded to the game.

However, as shown above, the game files have to go through additional steps when patching. If the 流程 is very slow, then that's an indicator for the 存储 device to be causing a 瓶颈. Moving / copying files requires additional space on your 存储. 通常 speaking the 补丁 requires at least as much free 存储 space as the game itself takes up. If there is insufficient free 存储 space, Steam will either abort the 下载 or offload the 流程 to another, possibly slower 存储 device on which a Steam 图书馆 is located.

As it also has to unpack heavily compressed files, this 流程 takes up considerable load on your CPU for unpacking and organizing the 补丁. The unpacking is done in real-time which means any other processes that are currently running might be interfering with your performance or 经验值 stuttering for the 持续时间 of the patching 流程, depending on your hardware.

存储驱动器

It is possible to 经验值 slow patching speeds even with the 使用 of SSDs. A lot of budget solutions are particularly slow when updating the game.

If you want to check on your 存储 device

  1. Open the Task Manager
  2. Click on the "Performance" tab.
  3. Check the active time of your disk. If it's 100%, then you have the 确认 that slow patching是实际上 cause by your 存储 device.

It's 重要 to note though that just a slow patching 流程 doesn't mean that the drive itself is bad; such speeds can also be caused by other factors, such as:

  • Anti-Virus 软件 constantly scans during the patching 流程. This can be 已解决 by deactivating the Anti-Virus for the 持续时间 of the 补丁.
  • A nearly full 存储 device and a patching 流程 that needs appropriate space to quickly 更新.
    • While in the past this was approximated at ~110 GB, these days giving it 50+ GB is recommended. Additional space, especially on the drive that contains your Operating system is good for the pagefile (see Virtual Memory) as well as files like hiberfil.sys and obviously driver & windows updates. Extra headroom is 正面 for a system's performance.
    • Please note that having sufficient free space does not mean that the 补丁 is guaranteed to be done quickly, just that it will eventually 补丁. If your SSD is filled over 50% of its 容量, you may 经验值 slow updates due to your SSD encountering problems when being nearly full.
  • Steam can be slow if you have it installed on a slow SSD or HDD, even if you moved 绝地潜兵 to different, fast, 存储.

In the event of your 目标 device having insufficient space for 绝地潜兵 2, Steam will opt to utilize other drives with existing Steam Libraries instead. Especially during larger updates, Steam prefers using the largest available 存储 device with an existing Steam 图书馆 on it to ensure a successful 更新.
In practical terms this means that even if your 绝地潜兵 2 installation is located on an SSD, if that SSD has insufficient space, Steam might use a slower HDD instead to handle the operations necessary to 补丁 the game.[1] It is possible to circumvent this by removing the larger drive from your 图书馆 before patching and then adding it back in after the 补丁 is done.

If you wish to analyze whether Steam is using your SSD, open up your Task Manager and check which drive is currently in use. If you 确认 that the wrong drive is used for the patching 流程, you can follow these steps:

  1. Quit out of Steam
  2. Open the folder where Steam is installed and open the /steamapps/-folder. The 默认 installation folder is C:\程序 Files (x86)\Steam\steamapps.
  3. Look for the libraryfolders.vdf-file and open it with Notepad.
  4. Then make note of the C:/.../steam 编号 for your SSD. It is 通常 either 0 or 1 .
  5. Go back into /steamapps/ and look for the file appmanifest_553850. This is the HD2 下载 instructions file, open it with notepad.
  6. Look for the code line Stagingfolder and change the number to your SSD. Once this has been set, save the file and close it.
  7. Now open Steam Settings via the button on the upper left corner of Steam.
  8. Navigate to 下载 and press 清除缓存. This will 重新开始 Steam and you will have to log in again. 注意: clearing the caches WILL wipe any 下载 progress on the 补丁 so you have to 重新开始 it again.
  9. After Steam restarts and you are logged back in it should now be using the SSD!

下载区域

If the 存储 device isn’t causing any issues, the slow 速度 could be caused by Steam's 下载 regions.

Steam distributes game files via localised “内容 运送 Networks” (CDNs). When a popular game such as 绝地潜兵 2 receives a major 更新, the 下载 servers in regions with high player counts can 有时 become heavily congested, which can bring 下载 speeds for 玩家 to a crawl. If you’re having issues with 下载 performance, it can 有时 help to change the 下载 region to access a 网络 that’s less congested – perhaps because 玩家 there are living in a different time zone and there’s less activity at that moment.

How to change your Steam 下载 Region:

  2. Navigate to the 下载 tab on the left 侧边栏.
  3. Locate the 下载地区 掉落-down menu.

  5. Steam will prompt you to 重新开始 the client for the 变更 to take 效果.
