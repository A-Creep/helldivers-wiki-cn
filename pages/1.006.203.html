⚖️ 平衡性调整

We have reverted the 虫窝护卫 and fixed an issue introduced in 补丁 6.2.1 where 护甲 values were incorrectly swapped between the Legs and Claws.

已更新虫窝护卫数据：

主体

  • 护甲 已增加 from  Very 轻型 →  轻型
  • 生命值 已增加 from 375 → 500

头部

  • 护甲 已减少 from  重型 →  中型

前腿

  • 护甲 已增加 from  轻型 →  中型
    • Note: This change refers to the 虫窝护卫's Frontal Tarsal Plate 护甲, which received an 护甲 减少 from  重型 to  中型.

利爪

  • 护甲 已减少 from  中型 →  Very 轻型
    • Note: This change occurred in the 上一个 补丁.

未记录变更

Keybinds

  • 绝地潜兵 not using the 标准 "QWERTY" keyboard layout now will find that the unbindable keys that replace certain UI functions now correspond to what their layout replaces 亲戚 to the 标准 keybinds. Where, by 默认, Q 和 E scroll the 难度 select on the 星系战争地图, 绝地潜兵 using a nonstandard layout such as DVORAK, will find that the apostrophe and period keys ' 和 . are used instead.
