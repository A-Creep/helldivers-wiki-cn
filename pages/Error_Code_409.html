Error Code 409

If you encounter a Crash to Desktop (CTD) or Black Screen of Death (BSOD), it's always good to check your Windows Event Viewer. Should you find error code 0xc0000409 in the Event Logs, then you can 卸载 OneNote for Windows 10 to 解决 the issue.

操作指南

  • Click "Start" and go to "Settings".
  • Click on "Devices".
  • Click on "Printers & Scanners".
  • Click on "OneNote for Windows 10".
  • Click "Remove Device"
