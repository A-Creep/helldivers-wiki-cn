断开 or 更新 USB Audio Devices

If your problems persist and you use any USB audio devices (such as a 耳机, 扬声器, or 麦克风), try unplugging the devices and test the game again. If this resolves the issue:

  • Check your device 制造商’s 网站 for driver updates.
  • If no updated drivers are available, you may need to use a non-USB audio device instead until an updated driver is available.

Modify Audio Engine Settings

Increasing the memory buffer size allows more audio data to be preloaded, reducing stutters and crackling from audio starvation.

  1. Right click in Steam, Hover over Manage and select Browse local files
  2. 打开 settings.ini in your preferred text editor.
  3. Find memory_size = 26214400 and replace it with memory_size = 78643200
  4. Save the file.

Optional: Please only change these if your CPU has 16 or more threads - otherwise you might lose performance!

  • Find num_reserved_threads = 2 and replace it with num_reserved_threads = 4

Attention: You will most likely have to re-do these steps after a game 更新.

Microsoft GameInput

It is recommended to first test a reinstall and if problems persist then to disable the 服务 completely.

What Is GameInput?

GameInput is an input API developed by Microsoft that 提供 a unified interface for a wide variety of input devices, including keyboards, mice, controllers, and other specialized peripherals. By standardizing input 操控性, GameInput allows developers to write code that works consistently across devices without needing to handle each device separately.

The API is designed with performance and simplicity in mind, providing low-latency input processing and built-in 支援 for advanced features such as vibration, force feedback, and simultaneous multi-device input. This makes it particularly useful for games that 要求 precise and responsive input 操控性.[1]

Why Should I Disable GameInput?

Since the release of Into The Unjust, a number of PC 玩家 have reported performance issues, especially when using controllers. These issues include input lag, stuttering and 崩溃.[2]

Player investigations have found that for some users GameInput can lead to degraded performance especially when using a controller. Disabling GameInput has been shown to 解决 a large majority of these issues for users with it still enabled.

Is Disabling GameInput Safe?

Yes, disabling GameInput is 通常 safe for most users. Very few applications or games rely exclusively on GameInput for controller 支援; most modern games provide fallback input 操控性 mechanisms.

If you disable GameInput and encounter issues with any other game or 应用程序, the change is fully reversible. Re-enabling GameInput restores normal functionality without impacting your system or installed 软件. Instructions to do so are provided along-side the instructions to disable GameInput.

Reinstalling GameInput

It is recommended to first try reinstalling GameInput before resorting to disabling it. The quickest and easiest method to do this would be the Hellbomb Script. If you want to do it manually, please follow the steps below:

Reinstalling GameInput

  1. Close the game.
  2. Open Windows PowerShell (Admin) using one of the following methods:
    1. 按下 ⊞ Win + X, then press A or select Windows PowerShell (Admin) from the menu.
    2. 按下 ⊞ Win + R, 类型 powershell into the Run dialog, then press Ctrl + Shift + 进入.
    3. Search for powershell in the Windows search bar and select Run as 管理员 from the panel on the right-hand side.
  3. Run the following commands, in order:
    1. winget 卸载 Microsoft.GameInput
    2. winget 安装 Microsoft.GameInput --accept-来源-agreements --accept-包-agreements
  4. 重新开始 your machine using one of the following methods:
    ⚠ Ensure you have saved anything 重要 before doing this ⚠
    1. 按下 ⊞ Win + X, then press U, then select 重新开始 from the open menu.
    2. Open the Windows Start menu, click the power icon, then select 重新开始 from the open menu.
    3. Run the 指挥: shutdown -r -t 0.

(Windows) DISM / SFC

If you are using Windows and encounter stuttering, it's worth at least trying once to check for potentially damaged Windows files and repair them. Via the 使用 of SFC ("System File Checker") you can let Windows check 受保护 system data for 伤害 and let it replace them with functioning copies from a local cache.

  1. 按下 WIN + R or Press "Start" and open the "Run" dialog.
  2. 类型 in CMD.
  3. Right click on it and choose "Run as 管理员".
  4. Now 类型 sfc /scannow into the CMD box.
  5. Once it's done, keep the CMD box open for the 下一个 steps.

After this has concluded, we will use DISM (Deployment Image Servicing and 管理). This 程序 will repair damaged Windows Images, Windows Updates and save components. It is capable of repairing files that SFC cannot repair.

Make sure to run these one by one as written:

  1. 类型 in dism /online /cleanup-image /scanhealth. Wait until it is finished.
  2. 类型 in dism /online /cleanup-image /checkhealth. Again, wait until it is finished.
  3. Finally 类型 in dism /online /cleanup-image /restorehealth.
⚠ Please be aware that these steps can take a bit to 完成. Please do not close or interrupt the 流程. ⚠

Scan / verify / repair Windows image may “freeze” at ~62.8%, this is completely normal and requires just a bit of patience. This step can take anywhere from 10 ~ 30+ 分钟, depending on your PC and your 互联网. Closing it halfway through is not advisable!

Once DISM is done, please 重新开始 your 电脑.
