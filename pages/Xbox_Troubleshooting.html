Basic Performance & 稳定性

These are basic steps you can perform if you encounter 崩溃, profile loading errors, performance drops and other problems.

Please be aware that "Quick Resume can cause issues.

Because 绝地潜兵 2 is a persistent live-服务 game, Xbox's "Quick Resume" 特性 will break your server 连接 when the 控制台 goes to sleep. This causes infinite black loading screens or profile sync failures upon waking. It's best practice to fully quite the game when you are done playing.

Press the "Menu button (☰)"" on the "绝地潜兵 2" tile and select "Quit".

Updates

Make sure to have the latest XBOX updates[1] installed.

  1. Go to "Settings".
  2. Open "System".
  3. Open "Updates & Downloads".
  4. 下载 and 安装 any available updates.
  5. The same should also be done for any connected peripherals if possible.

Please ensure that 内容 is fully installed before the 应用程序 is started.

Power Cycling & Clearing System Cache

Flushing temporary system files can 解决 random performance degradation. Just like computers are capable of clearing their cache so can the Xbox.

  1. Press and hold the "Xbox button" on the front of the 控制台 for roughly 10 秒 until it shuts off completely.
  2. Unplug the power cable from the back.
  3. Press and hold the power button a few times while unplugged to fully 放电 the internal capacitors.
  4. Wait 1 minute, reconnect the cable, and turn the 控制台 back on.

Clearing the Game & Profile Data

If your game 崩溃 on startup or you have 麻烦 loading up your player profile, you can clear the local data.

  1. Press Menu (=) on 绝地潜兵 2.
  2. Select "Manage Game Data and Add-Ons"
  3. Select "Saved Data".
  4. Select your Profile.
  5. Choose "Delete from 控制台".
⚠ 绝地潜兵 2 progress re-syncs from servers. However, for other games, deleting local data may cause permanent loss if not synced to the cloud. ⚠

If you want to clear the entire 更新 cache data, you can also do this:

  1. Select "My Games & Apps"
  2. Press the Menu Button (=) on the game.
  3. Select "Manage Game Data and Add-ons"
  4. Select "Saved Data"
  5. Select your Profile.
  6. Choose "Delete Everywhere".
  7. Now select "Reserved Space"
  8. Select "Clear Reserved Space".
  9. Finally select "Profile Data"
  10. Choose "Delete from 控制台".

Black Screen

If you 经验值 a black screen, please try these steps:

  • Check HDMI connections.
    • Use a different HDMI Port to test if the original port is bad.
    • Replace the HDMI cable if it is damaged.
  • Reset 显示 Settings
    • Turn off the 控制台 -> Press the power button while holding the Eject button to boot into low-分辨率 mode -> Reconfigure 显示 Settings.
  • If you have "Variable 刷新 Rate" on, test out other settings to see if the issue persists.
  • If possible, test another 显示 to check if the original 显示 is faulty.

Reinstalling the game

Reinstalling the game may be necessary if other attempts at resolving a 问题 fail.

  4. Choose "卸载 all" and then "卸载".
  5. Reinstall the game from your 图书馆 or the Xbox Store.
