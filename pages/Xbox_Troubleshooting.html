基本性能与稳定性

这些是你在遇到崩溃、资料加载错误、性能下降及其它问题时可以执行的基本步骤。

Please be aware that "Quick Resume can cause issues.

Because 绝地潜兵 2 is a persistent live-服务 game, Xbox's "Quick Resume" 特性 will break your server 连接 when the 控制台 goes to sleep. This causes infinite black loading screens or profile sync failures upon waking. It's best practice to fully quite the game when you are done playing.

在《绝地潜兵 2》磁贴上按“菜单按钮（☰）”，然后选择“退出”。

更新

Make sure to have the latest XBOX updates[1] installed.

  1. 开拓者 II/战斗日志
  2. 打开“系统”。
  3. 打开“更新和下载”。
  4. 下载并安装任何可用更新。
  5. 如果可能，对任何连接的外设也应执行相同操作。

Please ensure that 内容 is fully installed before the 应用程序 is started.

电源循环与清除系统缓存

Flushing temporary system files can 解决 random performance degradation. Just like computers are capable of clearing their cache so can the Xbox.

  1. 按住主机正面的"Xbox 按钮"约 10 秒，直到主机完全关闭。
  2. 从背面拔下电源线。
  3. 在拔掉电源的情况下，多次按住电源按钮以完全释放内部电容器的电荷。
  4. 等待1分钟，重新连接线缆，然后重新打开主机。

清除游戏与档案数据

如果你的游戏在启动时崩溃或加载玩家资料时遇到问题，你可以清除本地数据。

  1. 在《绝地潜兵 2》上按菜单（=）。
  2. 选择“管理游戏数据和附加内容”
  3. 选择“已保存数据”。
  4. Select your Profile.
  5. 选择“从主机删除”。
⚠ 绝地潜兵 2 progress re-syncs from servers. However, for other games, deleting local data may cause permanent loss if not synced to the cloud. ⚠

如果你想清除整个更新缓存数据，也可以这样做：

  1. 选择“我的游戏和应用”
  2. 在游戏上按菜单按钮（=）。
  3. 选择“管理游戏数据和附加内容”
  4. 选择“已保存数据”
  5. Select your Profile.
  6. 选择“全部删除”。
  7. 现在选择“保留空间”
  8. 选择“清除保留空间”。
  9. 最后选择“资料数据”
  10. 选择“从主机删除”。

If you encounter your 控制台 suddenly shutting off during intense activity, then this can 表明 problems with 温度 or power supply. It's worth observing this 行为; an 增加 in 频率 can 表明 that something is faulty. Also please check if the 问题 only occurs under 重型 load or if it happens randomly as this can 表明 what's going on exactly.

黑屏

如果你遇到黑屏，请尝试以下步骤：

  • 检查 HDMI 连接。
    • 使用不同的 HDMI 端口，测试原端口是否有故障。
    • 如果 HDMI 线损坏，请更换。
  • 重置显示设置
    • 关闭主机 -> 按住弹出键的同时按下电源按钮，以低分辨率模式启动 -> 重新配置显示设置。
  • 如果你开启了“可变刷新率”，请测试其它设置，看问题是否仍然存在。
  • 如果可能，测试另一台显示器，检查原显示器是否有故障。

控制器问题

如果你遇到控制器问题，请尝试以下步骤：

  • 确保更换控制器中没电的电池。
  • 按住主机和控制器的配对按钮，重新配对控制器
  • 确保固件已更新。
    • 前往设置 > 设备和连接 > 配件，检查更新。
    • 附近其它无线设备可能干扰连接

DLC/许可问题

Set the Xbox as your Home 控制台[2], as this can 修复 problems with DLCs and Licenses.

重新安装游戏

如果其它解决问题的方法都失败，可能需要重新安装游戏。

  1. 突出显示游戏。
  2. 按菜单按钮。
  3. 选择“管理游戏和附加内容”。
  4. 选择“全部卸载”，然后选择“卸载”。
  5. 从你的库或 Xbox 商店重新安装游戏。
