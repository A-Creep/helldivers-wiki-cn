什么是 Hellbomb 脚本

Hellbomb Script is a community-made diagnostics tool created by Discord user @bobthebuilder5001[1] who is a community hero in the 官员 绝地潜兵 2 Discord.

It is designed to automate common diagnostic steps and system checks for 故障排除 various issues. The script has various functionalities as described in a later 章节.

如何分享 Hellbomb 脚本结果

隐私与安全

The Hellbomb Script’s output is designed to contain 否 personal or sensitive information, and is therefore safe to share publicly or with others.

When running option [T], some 列兵 IP addresses may appear. These are non-unique and cannot be used to 识别 you—unlike your public IP 地址.[2] If you wish to verify that the addresses shown are indeed 列兵, 请参阅 this Wikipedia 条款, which lists the IP ranges reserved for 列兵 use.

推荐步骤

The output of Hellbomb Script option [H] can get quite long and often doesn't fit easily in a single screenshot. Because of this it is recommended to share it using the following method:

  1. Run the script with your chosen options and allow it to 完成.
  2. With the Hellbomb Script still in focus, Press Ctrl + A to select the entire output. then press Ctrl + C to copy.
  3. Either paste this output directly to the 位置 you are sharing the script or paste the output into a 文档 editor such as notepad and save the 目录 to a text file.

为何包含所有内容

Partial or "cherry-picked" logs can omit useful context that might not appear as [Fail] or [Warn], such as system 详情 or successful tests. For this reason it’s best to share the entire output.

常见问题

This is a list of common issues you may encounter when using Hellbomb Script and how to 解决 them.

cpuz_x64.exe 哈希验证失败

This occurs when you have previously used Hellbomb Script option [H] and have an old cpu-z_*.zip or cpuz_x64.exe in your downloads folder.

To 修复 this error, delete the existing cpu-z_*.zip and/or <cpuz_x64.exe files and re-run option [H].

错误：未找到'553850'区块或其内的'LaunchOptions

此错误表示脚本无法读取你用于绝地潜兵2的启动选项。

This can be safely ignored and will likely be 已解决 in a future version of Hellbomb Script
