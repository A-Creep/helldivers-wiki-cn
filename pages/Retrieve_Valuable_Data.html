目标 Steps[edit | edit 来源]

收集加密硬盘[edit | edit 来源]

“

加密硬盘被遗弃在这些坐标处。

— 目标 概述

  • 启动终端
    • 绝地潜兵 must interact with the 终端 to power it on.
  • 使用终端登录研究数据库
    • 绝地潜兵 must interact with the 终端 if not already, and then put in the 5 方向 code.
  • 使用终端启动紧急数据库备份
    • 绝地潜兵 must interact with the 终端 if not already, and then press the up 方向.
  • 数据库正在下载
    • 绝地潜兵 must wait the entire 20 秒 it takes for this step to 完成.
  • 使用终端弹出超级固态硬盘
    • 绝地潜兵 must interact with the 终端, then input the 7 方向 code
  • 收集 the SSSD 硬盘
    • 绝地潜兵 must go to the SSSD 硬盘 容器 and interact witth the SSSD 硬盘 to pick it up
  • 将超级固态硬盘转移至通信中继站
    • 绝地潜兵 must now hold onto the SSSD 硬盘 and 运输 it to the Communications relay.
  • (If the SSSD 硬盘 has been dropped) 恢复 the dropped SSSD 硬盘
    • 绝地潜兵 must pick up the dropped SSSD 硬盘 again

重新启动发电机[edit | edit 来源]

“

启动这台发电机可以为超级地球武装部队在该地区的设备提供急需的能源。

— 目标 概述

This Sub-目标 only occurs on 自杀任务 or higher

  • 启动终端
    • 绝地潜兵 must interact with the 终端 to activate it.
  • 登录终端
    • 绝地潜兵 must interact with the 终端, then 类型 in the 6 方向-long password
  • 请等待发电机诊断程序完成
    • It takes 15 秒 for the 顺序 to 完成
  • 使用终端重置熔断器
    • 绝地潜兵 must reset all 5 fuses by checking 5 boxes in a similar manner to the SEAF SAM Site
  • 使用终端，校准发电机电压
    • 绝地潜兵 must align the signal to reach 100% 力量, similar to a SEAF 大炮 or Terminate 非法 广播 目标
  • Wait for 发电机 to calibrate
    • It takes 30 秒 for the 发电机 to calibrate
  • 拉动变压器单元操纵杆
    • 绝地潜兵 must move to the 变压器 and interact with the large lever
    • There are large, yellow cables along the ground leading to the 变压器, along with a bright red 轻型 indicating the 位置 of the lever.
  • A 发电机 sub-目标
  • A 发电机's 变压器

通过当地转接设备上传数据[edit | edit 来源]

“

这个超级地球武装部队通信转接设备可以用于给行星轨道上的舰船发送信息。

— 目标 概述

绝地潜兵 may activate the 终端, but unless all Sub-目标 have been completed, the 终端 will be un-interactable with an error message displaying "Error - No Power".

  • 恢复卫星塔的电力输送
  • 使用终端抬升卫星塔
    • 绝地潜兵 must interact with the 终端 and input the 6 方向 code.
  • 正在抬升卫星塔
    • 绝地潜兵 must wait the entire 25 秒 for this step to 完成.
  • 手动重新对齐卫星塔
    • 绝地潜兵 must look at the 终端 to see the dishes' 当前 position and 目标 position, then communicate that information with other 绝地潜兵. Then a 绝地潜兵 must go and interact with the valve looking object, and use the left and right directions to move the 卫星 into the 正确 position. Then 绝地潜兵 must interact with the 终端 again and use the up 方向 to 确认 alignment. Then, 绝地潜兵 must wait the entire 5 秒 it takes for this step to 完成.
      • Unlike in the 卫星 Tower 可选目标, the 默认 position of the 卫星 dish does not point towards the valve looking object. Thus, communications must be adapted.
  • 正在向超级地球主机上传数据
    • Helldviers must wait the entire 40 秒 it takes for this step to 完成.
  • 使用终端抹除敏感数据
    • 绝地潜兵 must interact with the 终端, then input the 11 方向 long code to 完成 this step.
  • Reward: 申购点 and 100 经验值
