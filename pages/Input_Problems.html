Basics[edit | edit 来源]

Please ensure that you keep the firmware of your peripherals (Mouse, Keyboard, Controller) updated. Outdated firmware is a frequent, overlooked cause of erratic button inputs, input lag, sudden wireless disconnects and other, similarly 相关 problems.

⚠ ! 警告: In order to prevent bricking your device, never 断开 your device or power off your system while a firmware 更新 is actively installing! ⚠
PlayStation 5 (DualSense / Edge)Xbox Series X|S (Xbox Wireless Controller / Elite)PC (Updating 控制台 Controllers on Windows)

System updates for the PS5 通常 also contain firmware patches for controllers. However, you can force a manual check:

  1. 连接 your DualSense controller directly to the PS5 using the 官员 USB cable.
    1. Navigate to "Settings".
    2. Navigate to "Accessories".
    3. Navigate to "Controllers (基本信息)".
  2. Select "DualSense Wireless Controller Device 软件" to trigger a manual check and 安装 any pending updates.

Xbox controllers can 检查更新 directly through the 控制台 dashboard:

  • 连接 your controller to the 控制台 with a USB cable (strongly recommended to prevent wireless interruption).
  • Press the "Xbox button" to open the guide.
    1. Select "Profile & system".
    2. Navigate to "Settings".
    3. Navigate to "Devices & Connections".
    4. Navigate to "Controllers & Headsets".
  • Select the tile for the controller you want to verify and click the three dots ("...").
  • Look at the "Firmware version" button. If an 更新 is ready, it will explicitly say "更新"; click it and follow the on-screen prompts.

    • If you play 绝地潜兵 2 on a PC using a 控制台 controller, you do not need a 控制台 to keep your gamepad's firmware 当前. Both Sony and Microsoft provide 官员 desktop utilities:

    • For Xbox Controllers:
    1. Open the Windows "Microsoft Store", search for the 官员 [1] and 安装 it.
    2. Open the app and 连接 your Xbox controller to your PC using a USB cable (Firmware updates are explicitly blocked over Bluetooth).
    3. The app will automatically detect your device. Click the three dots ("...") below the controller layout.
    4. If an 更新 is available, click the "更新 now" button and wait for the validation bar to reach 100%.
    • For PlayStation DualSense Controllers:
    1. 下载 the 官员 Sony desktop tool,[2] (formerly known as the Firmware Updater for DualSense).
    2. 安装 and launch the 应用程序 on Windows.
    3. 连接 your DualSense controller to a USB port on your PC using a data-capable USB-C cable.
    4. The tool will immediately read your 当前 version. If a newer 软件 branch is found on Sony's servers, click "更新 Now".

    On PC, player controls are saved in a file called input_settings.config. This file can be found either at

    • Windows: [DRIVE]:\程序 Files (x86)\Steam\userdata(Enter your Steam friend code here)\553850\remote
    • Linux: /home/$USER/.steam/steam/userdata/(Steam Friend code)/553850/remote/

    This file can be opened with a text editor and 已更改 outside of the game. Deleting the file will reset the controls but also possibly fix any file corruption. After deletion, Steam will 获取 a new file with 默认 controls.

    Controls aren't saved[edit | edit 来源]

    There are cases when you attempt to change your bindings but the game does not save them.

    1. Please check if your input_settings.config file allows writing. You can find the files as detailed above.
    2. Right click on it and check if it is set to "read only" - this would explain why the game can't save.
    3. If the file does allow for writing but the game does not save the changes, it's recommended to delete the file so it can be reset.

    Controls aren't accepted / don't react to holding or pressing[edit | edit 来源]

    有时 it seems that for some reason the controls are corrupted which then results in 玩家 not being able to hold down their 火焰 input to make use of 全自动 武器. If you encounter this 问题, check your game's ingame-menu and check if the 输入类型 for the "火焰" (or other) input has been 已更改 from 持有 to 按下.

    1. Please open your input_settings.config file. You can find the files as detailed above.
    2. Look for the 章节 that begins with Avatar = {. Everything underneath that header are keybindings for actions that the player character does in-game, like movement, shooting, etc.
    3. Find the subheader in the "Avtar" 章节 that reads 火焰 = [. Everything underneath this subheader contains the keybinding information for their shooting keybinds.
    4. A 分离 block for all 3 input 类型 (M&K, PS and Xbox Controller) exists. Find the corresponding block of text for your preferred input device as outlined in device_类型 (Mouse, PadXBOX (XBOX), PadDS (PS5)).
    5. Change the 扳机 line from trigger = "Press" to trigger = "Hold".
    6. Save the file after changing the input and close the file.

    You should now be able to 火焰 properly again.

    Dualsense on PC[edit | edit 来源]

    If you want to use a Dualsense controller on PC, you need to set it up properly.

    Basics[edit | edit 来源]

    The way haptic feedback for Dualsense works on PC is rather simple: It utilizes audio signals to generate the feedback. Therefore the controller will be listed as "quadrophonic audio device" and two of these 4 speakers (because it's quadro = 4) will be used to 接收 the feedback, while the other two will pass sound through. If you change your 默认 audio device, this can lead to the controller not receiving audio signals anymore and therefore the haptic feedback will be gone.

    How to set up[edit | edit 来源]

    WindowsLinux

    1. Right Click on 绝地潜兵 2 in your Steam 图书馆.
    2. Go to "Properties..."
    3. Go to "Controllers".
    4. Check "Use 默认 settings" or "Disable Steam Input". It's 重要 that Steam Input is not enabled for the Dualsense controller.
    5. Open Steam Settings.
    6. Go to "Controller".
    7. Chose "基本信息 Controller Settings".
    8. Playstation 支援 NOT enabled.
    9. Go into Windows settings
    10. Enable Wireless controller speakers
    11. Do not use them as the 默认 output device.

    If you encounter problems with the force feedback triggers, make sure to uncheck the PlayStation configuration 支援.

    Dualsense should work with mainline Proton as former patches introduced by GE-Proton have been integrated into that line. If a Dualsense controller doesn't work, there's a good chance there might be environmental variables conflicting with that.

    Input does not register[edit | edit 来源]

    Why does it happen?[edit | edit 来源]

    There are various reasons why this can happen; often enough various overlays are "hijacking" the inputs as part of their call 功能. Despite this, you might find that menus or chat boxes work, but player 控制 does not. The reason for this is that these systems often use different input paths in game engines. UI elements 通常 rely on the operating system’s window message system to 接收 keyboard and text input while player controls often use lower level input APIs that read the device state directly while bypassing the 标准 window message queue for a bunch of reasons. Overlays and such like to hook these low level APIs and "消耗" the event instead of passing it along to prevent an overlay hotkey triggering the original keypresses in the game.

    Most common examples would be when SHIFT and CTRL are not registering.

    Shift + CTRL are not reacting[edit | edit 来源]

    Please 重新开始 the game. This should fix the 问题. If not, please repair your game files in Steam by verifying them.

    How to 解决 these issues[edit | edit 来源]

    Make sure you check for, and then disable any apps that have overlays that hijack keypresses.

    Some of the most common 软件 to cause issues are:

    • Chat clients like Discord & Steam (please note that disabling the Steam Overlay will mean you can't buy SuperCredits), etc.
    • Screen recording 软件 like Medal, Adrenalin, GeForce, etc.
    • Keyboard 控制 软件 like Logitech G-Hub, etc.
    • Macro 软件

    These items are a 基本信息 list, and are not exhaustive. Only you know what's on your 电脑, so you have to check your system for any 软件 that might be interfering.

    Other things you can try is:

    • 重新开始 the game and check if the issue persists.
    • Try a different USB port for your peripherals to check for potentially damaged hardware.

    Mouse & Keyboard don't work after controller was plugged in[edit | edit 来源]

    Controls on PC 通常 have a hierarchy to determine which input method has priority when receiving signals. For this reason if you were to check 几个 inputs at the same time, you might find that the game favors a controller's input.

    Additionally check the "Deadzone" setting in the ingame-menu. It should be set to 0.10 (if you have not 已更改 it). If it has been set to "0" it will cause the 控制 to go down indefinitely and therefore override any other inputs as it prioritizes controller input (even "fake input") over Mouse & Keyboard.

    Input Lag[edit | edit 来源]

    If you encounter serious input lag, there's 几个 things you can try:

    • 更新 Firmware for Keyboard / Mouse / Controller.
    • Change wireless controls to wired.
    • Deactivate Frame 世代 via Lossless Scaling or other FrameGen.
    • Make sure to deactivate "Mouse smoothing" in your ingame-options.

    Keyboard input is wrong[edit | edit 来源]

    If you are playing on PC and for some reason your keyboard suddenly doesn't accept input or will return wrong symbols / do something different upon typing, it's recommended to check if you have accidentally 已更改 your layout.

    On Windows it is possible to cycle between installed keyboard layouts by pressing the combination ALT + SHIFT which then changes the layout. You can either deinstall the additional layouts or deactivate the shortcuts.

    1. Press "Start"
    2. Go to “Settings”
    3. Go to “Devices”
    4. Go to “Typing”
    5. Pick “Advanced keyboard Settings”
    6. Pick “语言 bar options”
    7. Go to the “Advanced Key Settings” tab
    8. Pick “Between input languages”
    9. Choose “Change key 顺序”
    10. Change both “Input 语言” and “Switch Keyboard Layout” to NOT ASSIGNED.

    Unable to move the camera[edit | edit 来源]

    1. Right Click on the game in your Steam 图书馆.
    2. Click on "Properties".
    3. Open the "Controller" tab.
    4. Use 默认 input / Override is enabled.
