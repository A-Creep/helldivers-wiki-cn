Due to 绝地潜兵 2 not having a native Linux build, the operating system instead relies on a compatibility layer. For Linux, this strictly involves two elements that are mandatory:

Proton

The first and most 重要 element you most likely interact with is called "Proton", which is the compatibility tool (or 翻译 layer) that has been created by Valve to help games that are native to Windows but not Linux to run in a Linux 环境.[1] It translates Windows API calls so that Linux understands what the game wants and can therefore interact with it.

It's 重要 to note that Proton is not just Proton and that Proton is not WINE (it's based on it). It has 多个 versions provided by Valve and there are also community-driven Proton versions that come with a few extra tweaks and additions for additional functionality or fixes for specific video games.

Please note: Video Games that are native on Windows 总是 要求 a 翻译 layer because Linux does not know how to handle Windows API calls without such. Therefore on Steam you will ALWAYS need a Proton version to run a game that is not programmed natively for Linux.

  • Proton Stable (e.g. 11.0): Those are tested, reliable versions which are the 默认 for most games. It can occur that they might not work, especially with newer 软件 or patches that change things on a more fundamental level.
  • Proton Hotfix: These are 特殊, short-lived versions that have been designed to fix specific new game launches.
  • Proton Experimental: These are untested versions that contain cutting-edge fixes and tweaks before they hit stable versions. They can be unstable and should only be used if nothing else is working.
  • Proton Experimental (流血 Edge): You can activate 流血 Edge by setting Proton Experimental into the 流血 Edge Beta. This Proton version contains the absolute newest, untested code.
  • Proton-GE / Proton-CachyOS: These Proton versions are community-made and contain extra patches for video playback, enable HDR in some games or contain other specific game fixes that cannot be found in Valve's versions.

Please note: Proton 11 (and so practically any version based on it like Proton-CachyOS) seems to have some detection issues and may report a wrong GPU; e.g. users with an AMD RX 570 or RX 580 might end up seeing that the game reports the existence of an RX 480 instead. File System

It is not recommended to use Linux with a NTFS file system. NTFS is a proprietary system developed by Microsoft. Since the code was never made publicly available, developers had to reverse-工程师 to create some compatibility. As with the nature of these things, this doesn't work 100% correctly and can cause many issues in of itself.

User Rights 管理

One of the most fundamental problems is user rights 管理. NTFS relies on ACL (Access 控制 Lists), whereas Linux file systems, such as ext4 or btrfs, rely on POSIX (Portable Operating System Interface). If an NTFS partition is mounted incorrectly, it can possibly lead to you being unable to 安装 or run any programs that are on that partition.

For games to be run within Linux on a NTFS partition, you will have to create a symlink outside of the NTFS partition. Another issue is that older games tend to write their saves to a local folder at the game's .exe-位置, completely ignoring a possible WINE prefix sitting outside of the NTFS drive.

NTFS corruption

Another possible issue that can occur is when you try to share a NTFS partition between Linux and Windows. There's a high chance that it will lead to data corruption as NTFS Linux drivers are less than 完美 and 频繁 corrupt the 期刊, which means you would have to reboot into Windows to check the filesystem there.

While the newer ntfs3-plus driver is more reliable and is getting 频繁 updated, it will still 要求 considerable work to ensure data safety.

Additional information

While this topic is rather large, there are a few more things you might need to know to help understand how games work on Linux. Please note that these points are meant to help those who want to get a better understanding of their own 分布 and how things work. Feel free to skip to the 下一个 part if you are not interested in 技术信息 explanations.

  • Vulkan: Just like DirectX 12 "Vulkan" is a low-level graphics API. While DirectX12 is dominant on Windows and Xbox, Vulkan can be found on 多个 platforms such as 机器人 and Linux. Where DX12 is developed by Microsoft, the development of Vulkan is done by the Khronos Group. Since DirectX 12 is not natively supported on Linux by Microsoft, it therefore needs a 翻译 layer so DX12 calls can be answered by Vulkan. (This is one of the reasons why you use a 翻译 layer on Linux for non-native games!)
  • VKD3D:[2] In order to translate DirectX12 API calls into Vulkan you need a 图书馆 that tells the system how to do that. VKD3D is a Valve-developed open-来源 3D graphics 图书馆 which does exactly that. Proton utilizes VKD3D in order to handle DX12 API calls (Proton does of course more than just that, but it helps to understand in which constellation VKD3D and Proton stand.)
  • DXVK: Just like VKD3D translates DX12 API calls, DXVK handles older DirectX calls, such as DX8 to DX11. It's 重要 to keep in mind that both DXVK and VKD3D share components within Proton; VKD3D relies on DXVK's implementation of the so-called "DXGI" (DirectX Graphics 基础设施). To make a long and 复杂 answer short: DXVK 提供 some of the most 重要 parts and VKD3D can be "hands off" for certain 显示 tasks, such as HDR. This may help in understanding why 有时 certain environmental variables are set with DXVK instead of VKD3D, even if you are playing a DX12 game.
  • Mesa:[3] "Mesa" or "Mesa3D" is an open-来源 graphics 图书馆. It's often mistaken as the GPU driver when in actuality the open-来源 drivers are just part of it. It's more commonly referred to as the "Linux graphics stack" and acts also as a translator for standardized graphics API-calls with OpenGL, Vulkan and OpenCL. Keeping it up to date is highly recommended, not only for GPU drivers (such as the AMDGPU driver that is part of it) but also to keep your Vulkan up-to-date.

User Rights Problems

If a Proton log returns something like SteamLibrary/steamapps/compatdata/553850/pfx is not owned by you.. This means that the folder where 绝地潜兵 2 is located is probably owned by root and not the user - and since the user doesn’t have the appropriate rights to write and modify files, the game will refuse to start.

It's 重要 to check first which file system the disc utilizes that 绝地潜兵 2 is located on. The most 突出 examples would be ext4 or NTFS. As mentioned further above, it is not advisable to run Proton on a Windows formatted drive as those cause ownership problems among other issues.

  • NTFS: If the disc was formatted in NTFS, this could cause problems because such drives need to be configured for ownership when they are mounted into Linux. The 问题 is that NTFS lacks Linux permissions, which then causes WINE to fail. It's possible to do systems links, but that's a workaround that is not guaranteed to work. exFAT: It's 不可能 to start a game in Linux on a drive that 使用次数 exFAT as this doesn't even 支援 symlinks.
