Virtual Memory

Virtual Memory is a memory 管理 technique utilized by a 电脑's operating system. By using a designated portion of secondary 存储 devices (such as SSDs or HDDs), it extends the system's available memory pool beyond its 物理 limits (RAM).

Basics

Every system has a 有限 pool of 物理 memory, known as RAM. Once the RAM is fully saturated, the system has no more space to store and 回收 active data. This immediately leads to 稳定性 issues, resulting in random desktop 崩溃, severe stuttering, or even full system hangs like Blue Screens of Death (BSOD). Virtual memory prevents this by outsourcing less 致命 active files onto the system's secondary 存储.

However, it is 重要 to note that secondary 存储 is significantly slower than 物理 RAM. Therefore, virtual memory is not a viable method for boosting raw gaming performance, and it cannot magically replace 物理 RAM. Instead, it acts strictly as a safety net to 维护 system 稳定性 when 物理 memory runs out.

As a rule of thumb, the less 物理 RAM a system has, the more 致命 proper virtual memory configuration becomes. Systems with 16GB of RAM or less must absolutely ensure their virtual memory is enabled and correctly configured. Even systems with larger memory pools (32GB+) should never deactivate virtual memory, as many modern games and Windows services rely on its presence to avoid unforeseen 崩溃.

Setting the Virtual Memory

⚠ 重要, read the 下一个 three points carefully! ⚠
  • If you have both an SSD and an HDD, place the page file on your HDD! Placing it on a SSD can cause drastic wear & tear if you regularly run out of 物理 memory. Furthermore some processes will inevitably write things onto the pagefile to free up valuable RAM. Using the SSD might be faster but the wear&tear should always be kept in mind!
  • Do NOT disable the page file.
  • Do NOT set it to 0MB.

重要: If Windows has no virtual memory (pagefile) enabled, it cannot generate a crash dump (minidump) to help you analyze what caused a system crash.

Linux offers two methods for configuring virtual memory: a dedicated SWAP partition or a SWAP file. Some distributions 要求 users to configure a partition during the initial OS installation.

通常, it is recommended to use a dedicated SWAP partition rather than a SWAP file. Even Linus Torvalds has emphasized the 稳定性 benefits of using a proper partition over a file setup.[2]

The ideal size of your SWAP partition depends heavily on two factors:

  • The amount of 物理 RAM installed.
  • The primary workload of the system.

While 历史 tech advice recommended setting the pagefile or SWAP partition to 1.5x or 2x your RAM, modern 要求 have shifted. Red Hat 提供 官员 guidelines that lean toward system hibernation needs rather than gaming 优化. For gaming, the 经典 rule still holds some value: the less 物理 RAM you have, the larger your SWAP partition needs to be to prevent out-of-memory 崩溃.[3]

Additionally, zRAM is 频繁 recommended as a modern way to handle virtual memory via RAM compression. However, it is 重要 to note that zRAM utilizes real-time CPU compression, which can introduce extra CPU overhead. If your CPU is already heavily utilized by games like 绝地潜兵 2, using a traditional, uncompressed SWAP partition on a fast drive may yield more stable gaming performance when 物理 memory is exhausted.
