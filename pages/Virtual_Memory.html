Virtual Memory

虚拟内存 is a memory 管理 technique utilized by a 电脑's operating system. By using a designated portion of secondary 存储 devices (such as SSDs or HDDs), it extends the system's available memory pool beyond its 物理 limits (RAM).

基础

Every system has a 有限 pool of 物理 memory, known as RAM. Once the RAM is fully saturated, the system has 否 more space to store and 回收 active data. This immediately leads to 稳定性 issues, resulting in random desktop 崩溃, severe stuttering, or even full system hangs like Blue Screens of Death (BSOD). Virtual memory prevents this by outsourcing less 致命 active files onto the system's secondary 存储.

However, it is 重要 to note that secondary 存储 is significantly slower than 物理 RAM. Therefore, virtual memory is not a viable method for boosting raw gaming performance, and it cannot magically replace 物理 RAM. Instead, it acts strictly as a safety net to 维护 system 稳定性 when 物理 memory runs out.

As a rule of thumb, the less 物理 RAM a system has, the more 致命 proper virtual memory configuration becomes. Systems with 16GB of RAM or less must absolutely ensure their virtual memory is enabled and correctly configured. Even systems with larger memory pools (32GB+) should never deactivate virtual memory, as many modern games and Windows services rely on its presence to avoid unforeseen 崩溃.

设置虚拟内存

⚠ 重要, read the 下一个 three points carefully! ⚠
  • If you have both an SSD and an HDD, place the page file on your HDD! Placing it on a SSD can cause drastic wear & tear if you regularly run out of 物理 memory. Furthermore some processes will inevitably write things onto the pagefile to free up valuable RAM. Using the SSD might be faster but the wear&tear should always be kept in mind!
  • Do NOT disable the page file.
  • Do NOT set it to 0MB.

重要： If Windows has 否 virtual memory (pagefile) enabled, it cannot generate a crash dump (minidump) to help you analyze what caused a system crash.

  1. 按下 WIN + R 以打开"运行"对话框。
  2. 类型 sysdm.cpl 到文本框中，然后点击"确定"。
  3. Navigate to the "Advanced" tab, then click the "Settings..." button under the "Performance" 章节.
  4. In the "Performance Options" window, click the "Advanced" tab.
  5. Ensure that "处理器 scheduling" is set to "Programs".
  6. Click the "Change..." button under the "Virtual memory" 章节.
  7. Check the box at the very top: 自动管理所有驱动器的分页文件大小.
  8. Click "OK", apply the 变更, and 重新开始 your 电脑 for them to take 效果.

如果你希望手动设置大小，请取消勾选自动管理复选框，选择"自定义大小"单选按钮，并将初始大小设置为不低于(0.25 * RAM)，最大大小设置为(1 * RAM + 257MB)。[1]

Linux提供两种配置虚拟内存的方法：专用SWAP分区或SWAP文件。某些发行版要求用户在初始OS安装期间配置分区。

通常建议使用专用SWAP分区而非SWAP文件。即使是Linus Torvalds也强调过，与文件设置相比，使用正规分区在稳定性方面的优势。[2]

SWAP分区的理想大小主要取决于两个因素：

  • The amount of 物理 RAM installed.
  • The primary workload of the system.

虽然历史上的技术建议推荐将页面文件或SWAP分区设置为内存的1.5倍或2倍，但现代需求已经发生变化。Red Hat提供的官方指南更倾向于满足系统休眠需求，而非游戏优化。对于游戏而言，经典规则仍有一定价值：物理内存越少，为防止内存不足崩溃，SWAP分区就需要越大。[3]

Additionally, zRAM 常被推荐为一种通过RAM压缩处理虚拟内存的现代方式。然而需要注意的是，zRAM使用实时CPU压缩，可能带来额外的CPU开销。若CPU已被《绝地潜兵2》等游戏大量占用，在物理内存耗尽时，使用传统未压缩的SWAP分区（位于高速驱动器上）可能带来更稳定的游戏性能。
