修复[edit | edit 来源]

崩溃修复[edit | edit 来源]

  • Fixed a rare crash caused by weapon reloads
  • Fixed a rare crash when opening chat on a 任务.
  • 已解决 crash 相关 to squad menu.
  • Fixed crash that might happen if host migration occurs during a 虫族入侵.
  • Fixed crash when opening the 军械库 or 舰船管理 and 采购 menu at the same time when on someone else's ship.
  • Fixed a UI crash where there could be more than 3 teammates at the same time.
  • Fixed a crash which occurred after an early host migration and the former host having an unique 皮肤 in their 绝地喷射舱.
  • Fixed crash that could happen if a peer leaves a four-player game.

Miscellaneous Fixes[edit | edit 来源]

  • the SH-32 防护罩生成包 now properly transfers 击退 to the wielder.
  • Fixed 绝地潜兵 cardboard not 生成 in the tutorial.
  • Fixed a bug where 绝地潜兵 arms would glitch when quickly picking up the same 武器类型 twice.
  • Fixed owned 战略配备 number increasing for all categories when 战略配备 is purchased.
  • Fixed issue with overlapping input for Rock Paper Scissor first option on the controller.
  • Fixed the Expert Exterminator 标题 being incorrectly available to some 玩家.
  • Fixed the issue where all the medals of a 战争债券 page would hide when scrolling.
  • Scout walkers will now 接收 the 毒气 困惑 效果 when damaged by 毒气. They will also properly take 伤害 on their 生命值 zones when receiving 伤害 from flamethrowing or 毒气 武器.
  • Fixed name of the new host not showing anymore for clients when host migration happens.
  • Fix backpack being hidden while in the 重机枪阵地.
  • 已解决 an issue where PS5 玩家 became unjoinable after their 控制台 returned from rest mode.
  • Fixed issue where a poor 连接 between a joining player and an existing player could cause the existing player to be disconnected from the session. For good measure, we also doubled the threshold for what is considered a poor 连接. This should result in less instances of being randomly sent back to your ship without 警告 or reason.
  • Fix a host migration issue for 战略配备 目标 that prevent their completion.
  • Fix bug where 有时 前置条件 目标 would be shown above the primary 目标 in the HUD.
  • Fixed tentacles throwing the player in the air when 穿刺虫 recalled them.
  • Fixed bug in "疏散高价值目标" where 敌人 would stop 生成 for a period of time when the host leaves.
  • 所有 机器人 Hulk 类型 will now prioritize the player over the Power 发电机 in the 撤离高价值资产 任务.
  • Fixed broken menus when opening the main menu right before entering the 绝地喷射舱 (when the 武装配置 menu opens).
  • 基本信息 Brasch was promoted to Super 10-Star 基本信息 after the latest personal 防护罩生成器 困惑.
