护甲 属性

Armors have three primary 属性: 

• 护甲值 : Represents the 护甲's 能力 to absorb 伤害.
• 速度        : Determines how quickly the 绝地潜兵 can move across the battlefield.
• 耐力 Regen: Affects the regeneration of 耐力, which is used when sprinting and performing other strenuous actions.


护甲值 增加 or 降低 受到伤害 using the following formulas: 

• If 护甲值 ≥ 150
  ◦ 受到伤害 = 攻击 伤害 × (1.5 - 护甲值 ÷ 200)
• If 护甲值 ≤ 150
  ◦ 受到伤害 = 攻击 伤害 - ((护甲值 - 25) ÷ 5)


速度 is calculated based on the raw 护甲值 属性 (before factoring in passives like 额外垫料) using the following formula: 

• 速度 = 600 − 护甲值

耐力 Regen is similarly calculated using these formulas: 

• If 护甲值 ≥ 100
  ◦ 耐力 Regen = 200 − 护甲值
• If 护甲值 < 100
  ◦ 耐力 Regen = 150 − 护甲值 ÷ 2
