生成[edit | edit 来源]

强袭虫 Behemoths can be first found on 中型 作为……的任务目标 消除 Chargers 任务.

Starting on 自杀任务, the 巨兽级强袭虫，与……一起 Spore 强袭虫，会有几率取代强袭虫。更高难度会提高这个几率。与强袭虫一样， 强袭虫 Behemoths can spawn from 虫族入侵们，与其他终结族一起在地图上巡逻，并守卫 目标。它们也可能守卫着重型 Bug Nests, 超级绝地潜兵难度的超大型巢穴，以及 Minor Places of Interest，在那里它们有时会钻地藏身。

行为[edit | edit 来源]

强袭虫 Behemoths 行为与强袭虫相似. 与强袭虫相比，它们的生命值和耐久度略高。

战术信息[edit | edit 来源]

强袭虫 Behemoths can be dispatched with the same 对付强袭虫的战术.

  • 尽管生命值更高， 巨兽级强袭虫 与强袭虫共享许多反坦克武器击杀阈值：从……直接命中躯干 FAF-14 Spear 会立即消灭它，而其他反坦克武器需要爆头。强袭虫暴露躯干的加成伤害同样适用于 巨兽级强袭虫.
    • G-123 铝热剂手榴弹如果粘在躯干上，不会立即消灭 巨兽级强袭虫 爆炸时。瞄准头部可确保一击必杀。
    •  重型 穿透支援武器对……造成的伤害会降低 巨兽级强袭虫 身体大部分区域，但由于巨兽的生命值和耐久度更高，这比用同样方法消灭普通强袭虫更慢。
